# 06. 서비스접수

## 무엇을 하는 화면인가
왼쪽 메뉴 **서비스접수**. 고객 전화·카톡·사내 요청으로 들어온 일을 접수하는 화면입니다. 주로 PC에서 씁니다.
임대리스트에서 업체를 고르면 기기 정보가 자동으로 채워지고, 버튼 한 번으로 **접수 저장 · 접수 시트 기입 · 팀 AS 카톡방 · 일정리스트 · 네이버 캘린더**까지 이어집니다.

맨 위 한 줄 **종류 탭**(칸마다 열린 건수)
- 현장: **[CS 접수] [원격] [IT]** — 2026-10-25 "복합기 AS" 를 **CS 접수**로 이름만 바꿨습니다(화면 글자만. 저장 값·시트·카톡 양식은 그대로 "복합기 AS", 목록 칩은 "CS")
- 지원: **[경영지원] [운영지원] [영업팀]** — 관리 탭 "서비스접수 지원 3종" 스위치가 켜져 있을 때만 보입니다(2026-10-22 켜져 있음).

왼쪽은 접수 쓰는 곳, 오른쪽 기둥은 **[접수리스트 | 미처리 현황]** 전환입니다.

## 순서대로 쓰는 법 — CS 접수(옛 복합기 AS) · IT
1. 종류 탭에서 **[CS 접수]** 또는 **[IT]**.
2. 거래처 선택: **기존**이면 검색칸("임대리스트 검색 — 업체명·부서명·자산·시리얼·순번")에 치고 Enter. 결과 줄에서 맞는 기기를 누릅니다. 임대리스트에 없으면 **신규**로 바꾸고 업체명을 직접 적습니다.
   - 결과 줄에 **부서명 회색 알약**(임대리스트의 부서명/현장명)이 붙습니다. 부서명으로 걸린 줄은 알약에 노란 테두리가 있습니다.
   - 검색 순서: 업체명 → 부서명 → 자산 → 기번 → 순번. 숫자만 치면 부서명 단계는 건너뜁니다.
3. 고른 기기 카드에서 순·모델·자산번호·기번·등급·지역·종료일·미수·**부서**를 확인합니다. 틀리면 "⚙️ 자동 입력값 수정"을 펼쳐 고칩니다. 같은 업체에 기기가 여러 대면 노란 줄이 뜨니 자산·기번을 꼭 대조하세요.
4. 접수 내용: 카카오/전화, 임대리스트 순번, 접수분야(복합기만: A/S·점검요청·여분요청·세팅요청·불만·미수·해지방어·직접기재), **접수자 성함·연락처**, 제목(짧게, 복합기 필수), **증상/내용**, **방문 주소**(임대리스트와 다르면 실제 주소로 고침), 팀 지역, 증상 사진(최대 6장, PC는 칸 클릭 후 Ctrl+V), 유상/무상·교체이력·참고사항.
5. 아래 회색 **카톡 보고용 양식**이 자동으로 만들어집니다. 이 글이 그대로 카톡·네이버·일정 내용이 됩니다.
6. 하단 띠의 필수 칩(업체 · 접수자 · 연락처 · 제목 · 내용 · 주소 · 순번)이 모두 초록이면 **[⚡ 전체]** 를 누릅니다 = 접수 + 시트 + 일정 + 네이버 + 카톡 한 번에. 따로 하려면 **[접수] [네이버 캘린더] [카톡 전송]**. 어떤 순서로 눌러도 접수는 한 번만 저장됩니다.
7. 시트를 확인하려면 **[시트 열기]**.

## 순서대로 쓰는 법 — 원격
1. **[원격]** 탭. 거래처를 고르고 접수 내용을 적습니다(방문 주소·카톡 양식 없음).
2. **[접수 (저장+시트)]**. 원격대기로 저장되고 원격 시트에 들어갑니다. 네이버·카톡은 없습니다. **[원격 시트]** 로 확인합니다.
3. 접수리스트에서 그 줄을 펼쳐 처리 시작·끝 시각, 처리자, 추가대수, 처리내용을 적습니다.

## 순서대로 쓰는 법 — 경영지원 · 운영지원 · 영업팀
1. 지원 탭 중 하나를 누릅니다. 맨 위에 **접수자**(로그인한 이름)가 보입니다. 사내 요청이면 요청자를 고릅니다.
2. **거래처 선택**은 복합기와 같은 검색(임대리스트 + 부서명). 없으면 신규 거래처 업체명.
3. **접수유형**(카카오·전화·메일·사내 요청) · **접수분야**(칩 + 직접 입력) · 업체담당자 · 전화번호 · **접수내용** · 특이사항(앱에만 저장) · 처리자(지역 기본값) · 경영지원은 계약서구분(전자·수기) · 예정일.
   - **예정일을 넣으면 부서 달력**(서비스접수 탭 부서 화면의 일정)에 올라갑니다. 부서 일정·접수는 서비스접수 탭에서 모아 봅니다(2026-10-25, 일정 탭의 경영·운영·영업 칩은 없앰). 네이버로는 가지 않습니다.
4. **[접수 저장]**. 저장 → (영업·경영) 시트 기입 → (예정일) 부서 달력. 방금 같은 내용을 저장했으면 "같은 내용을 방금 저장했습니다. 한 건 더 저장할까요?"가 뜹니다. 시트 기입이 20초를 넘으면 화면엔 "시트 반영 대기"로 끝나지만 서버는 끝까지 적습니다 — 그 뒤 [완료]·배정·[다시 보내기] 때 앱이 적힌 행 번호를 찾아 접수에 붙이고 시트 처리 칸도 고칩니다(2026-10-25 고침, 그 전엔 시트 갱신을 건너뛰어 시트가 '진행중'에 남았음).
5. 처리할 때는 접수리스트에서 펼치거나 미처리 현황 카드에서 단추를 누릅니다: **[완료]**(처리내용 선택 → [완료 확정]) · **[내일로]**(다음 영업일) · **[날짜 고르기]** · **[보류]**(다시 누르면 [보류 풀기]) · **[메모]**(영업은 진행 메모 칩도) → [메모 저장]. 상세에서 [수정]·[삭제]도 됩니다.

## 경영·운영·영업 미니 업무공간 (2026-10-24)
지원 3종(경영지원·운영지원·영업팀) 화면에서는 다른 탭을 오가지 않고 이 화면 하나에서 일정 확인·배정·완료까지 합니다. 현장 3종(복합기 AS·원격·IT) 화면은 바뀌지 않았습니다.
1. 지원 탭을 고르면 오른쪽 전환 막대가 **[일정리스트 n | 달력 | 접수리스트 | 미처리현황 n]** 4칸이 됩니다(달력은 2026-10-25 추가). 처음엔 일정리스트가 열리고, 마지막에 본 칸을 기억합니다(현장 화면의 기억과 따로).
2. **일정리스트**: 칩 **[금일][익일][예정]** 3개.
   - 금일 = 예정일이 오늘 · 익일 = 다음 영업일까지(금요일이면 토·일·월) · 예정 = 그 뒤(날짜 칩은 예정일·부서 일정 기준). 처음엔 금일이 열립니다.
   - **[미처리] 칩은 없앴습니다**(2026-10-25 밤 사용자 "미처리현황 탭과 중복"). 예정일이 지났거나 비어 있는 접수는 일정리스트에 나오지 않고 **[미처리현황]** 탭에서 봅니다. (같은 날 낮에 넣은 "일정리스트 [미처리] = 미처리현황과 같은 목록"은 이 결정으로 되돌렸습니다.)
   - 전환 막대의 "일정리스트 n" = 금일(안 끝난 것) 수. 미처리는 "미처리현황 n" 으로 따로 셉니다.
   - 카드: 업체 · 분야 · 내용 한 줄 · 예정일 · **처리자 알약**. 알약을 누르면 배정 창(1명)이 뜹니다. 후보 = 부서 기본 처리자 + 관리 탭 인원 명단에서 그 부서(영업팀·경영지원파트·CSS/운영지원파트의 운영지원) 사람. 명단이 비면 이름을 직접 적습니다. 비우고 저장하면 미배정(빨강).
   - 배정은 접수의 처리자 칸을 바꾸고, 영업·경영은 **시트 처리자 칸**도 같이 고칩니다. 예정일이 있으면 부서 달력 메모의 "처리자" 줄도 맞춥니다. 카톡·푸시 알림은 보내지 않습니다.
   - 카드 아래 처리 단추는 위와 같습니다([완료]·[내일로]·[날짜 고르기]·[보류]·[메모]). 완료하면 카드가 빠지고, 내일로·날짜는 맞는 칩으로 옮겨 갑니다.
   - 접수와 연결 안 된 **부서 일정**(부서 달력에 직접 넣은 것)도 날짜 칩에 섞여 보입니다(오늘 이후 것만 — 지난 부서 일정은 [달력]에서 봅니다). 누르면 날짜·제목·메모를 고칠 수 있습니다. 머리의 **[＋ 일정 추가]** 로 새 부서 일정을 넣고, 삭제는 **[달력]** 에서 합니다(일정 탭의 부서 칩은 2026-10-25 없앴습니다).
3. **달력**: 그 부서 달력(점 격자 + 고른 날 목록, 폰·PC 같은 모양). ‹ › 로 달 이동, **[추가]**·날짜 두 번 누르기·**[이 날에 추가]** 로 새 일정, 일정을 누르면 수정·**삭제**. 접수에서 온 일정을 지우면 접수 예정일이 비워집니다(접수는 남음).
4. **접수리스트**: 예전 목록 그대로(부서 필터가 걸린 상태).
5. **미처리현황**: 홈 미처리 "경영/운영/영업" 탭과 **같은 숫자**입니다(같은 함수로 셈). **모든 줄**(앱 접수·시트에서 온 줄)에 홈과 같은 **[완료] [보류] [배정]** 이 있습니다(2026-10-25 밤 — 앱 접수 줄도 같은 단추로 통일. 미루기·메모는 일정리스트 카드와 접수리스트 상세에서). 무엇이 바뀌는지는 아래 "[완료]·[보류]·[배정]이 바꾸는 것" 표. **[완료]·[보류]는 확인창**이 먼저 뜨고, 취소하면 아무것도 바뀌지 않습니다. 시트 줄은 **시트의 상태·처리자 칸만** 적고 다른 칸은 건드리지 않으며, 순번·상호가 맞는 행에만 씁니다(행이 밀렸으면 순번으로 찾고, 못 찾으면 쓰지 않고 빨간 토스트). [완료]한 줄은 바로 빠지고, [보류]·[배정]은 줄에 바로 반영되며, 실패하면 원래대로 돌아옵니다. 줄을 누른 상세 팝업에도 같은 단추가 있고, 시트 줄은 "영업시트 n행 ↗" 작은 글자로 시트를 확인할 수 있습니다.
6. **[시트 열기 ↗]** 는 경영·영업 접수 폼 아래 **[접수 저장] 왼쪽**에 있습니다(2026-10-25 머리 어두운 줄에서 옮김): 영업 = 해지방어접수 탭, 경영 = 경영지원접수 탭을 새 창으로 엽니다. 운영지원은 시트가 없어 단추가 없습니다.
7. 60초마다, 창으로 돌아올 때 다시 읽습니다. 읽기에 실패하면 빨간 줄로 알려 주고 이전 목록은 그대로 둡니다. 배정 저장이 실패하면 카드가 원래대로 돌아가고 빨간 알림이 뜹니다.
- 일정 탭(캘린더·일정리스트)의 경영·운영·영업 칩은 2026-10-25 없앴습니다. 부서 일정·접수는 이 서비스접수 탭에서 합니다.

## 오른쪽 기둥 — 미처리 현황
1. 오른쪽 위 **[미처리 현황]** 을 누르면 종류별 미처리 칸이 보입니다(홈의 "미처리 접수" 카드를 눌러도 여기로 열림).
2. 숫자 띠: 종류마다 접수·진행중·보류 수, **오늘 접수**, **이번 주 완료율**. 카드는 오래된 순, 경과 3일 이상 노랑·7일 이상 빨강.
3. **모든 카드**(CS 접수·원격·IT·경영·운영·영업)에 홈 미처리와 같은 **[완료] [보류] [배정]** 이 붙습니다(2026-10-25 밤 — 그 전엔 시트 카드만). 종류별로 단추가 다릅니다: CS 접수 = [완료]만, 원격·IT = [완료]·[배정](보류 없음), 경영·운영·영업 = 셋 다. 바뀌는 것은 아래 표. **[완료]·[보류]는 확인창**("무엇이 바뀌는지" 문장)이 먼저 뜨고 취소하면 아무것도 바뀌지 않습니다. 누르면 카드가 **바로** 빠지거나(완료) 상태·처리자가 바뀌어 보입니다(60초 기다리지 않음 — 홈과 같은 "방금 누른 줄" 기억을 5분 씀). 현장 3종 카드에는 **"접수리스트/원격 대기열/IT 대기열에서 보기 →"** 작은 글자가 남아 원래 흐름으로도 갈 수 있습니다.
4. **시트 기준 모드**(관리 탭 "서비스접수 미처리 = 시트 상태 기준", 2026-10-22 켜져 있음): 영업·경영·원격·IT 숫자를 **실제 접수 시트의 상태 열**로 셉니다. 처리완료·취소·이관이 아니면 미처리입니다.
   - 시트에서 온 줄에는 "시트" 배지와 상태 글자가 붙고(빈 칸은 "상태 비어 있음"), 누르면 시트 카드와 **[완료] [보류] [배정]**(2026-10-25 — 시트 상태·처리자 칸에 적힘, 원격·IT 는 보류 없음)이 나옵니다. [완료]한 카드는 바로 빠지고(2026-10-25 밤부터), 실패는 빨간 토스트로 알리고 카드가 돌아옵니다. "시트 n행 확인 ↗" 글자로 시트를 열어 볼 수 있습니다.
   - 90일이 넘은 것은 **"90일 넘음 n"** 칩으로 접혀 있습니다.
   - 시트에서 처리완료로 바꾼 앱 접수는 앱에서도 자동으로 완료됩니다.
   - 시트 읽기가 실패하면 앱 접수 숫자로 보여 주고 안내가 뜹니다. 시트 반영은 1~2분 늦을 수 있습니다.
5. 일정 미처리(지난 날짜·미완료 물류·AS 일정)도 같이 보입니다.

## [완료]·[보류]·[배정]이 바꾸는 것 (2026-10-25 밤)
홈 미처리 팝업 · 서비스접수 현황판 · 부서 미니 업무공간 [미처리현황]이 같은 단추와 같은 규칙을 씁니다.

| 줄 종류 | [완료] | [보류] | [배정] |
|---|---|---|---|
| 시트에서 온 줄(영업·경영) | 확인창 → 시트 n행 상태 칸 **처리완료**(접수일·내용 그대로). 목록에서 빠짐 | 확인창 → 시트 상태 칸 **보류**(다시 누르면 진행중). 목록에는 "보류" 표시로 남음 | 이름 고르기 → 시트 **처리자 칸**에 적힘 |
| 시트에서 온 줄(원격·IT) | 확인창 → 원격 시트 상태 칸 **처리완료** | (없음) | 원격 시트 처리자 칸 |
| 원격·IT 앱 접수 | 확인창 → FIELD 접수 **완료** + 원격 시트 처리여부 **처리완료**(처리자가 비었으면 누른 사람) | (없음) | FIELD 처리자 + 원격 시트 처리자 칸 |
| 경영·운영·영업 앱 접수 | 확인창 → 접수 **완료**(완료자·시각) + 연결 부서 달력 일정 완료 + (영업·경영) 부서 시트 갱신 | 확인창 → 접수 **보류**(다시 누르면 진행중) + (영업·경영) 시트 갱신 | 접수 처리자 1명 + (영업·경영) 시트 처리자 칸 + 부서 달력 메모 |
| CS 접수 앱 접수(현황판) | 열린 연결 일정이 있으면 **일정리스트와 같은 완료 창**(그 일정 완료 → 접수 상태·접수 시트·네이버까지) / 일정이 없으면 확인창 → **접수 상태만 완료** | (없음) | (없음) |
| CS 접수·물류 일정(홈) | 일정리스트와 같은 완료 창 | (없음) | (없음) |

- 확인창에서 **취소**하면 아무것도 바뀌지 않습니다(목록·시트·토스트 그대로).
- 배정 창 제목 아래에 "저장하면 시트 처리자 칸에 적힘"이 보이고, 저장 뒤 토스트가 "홍길동 에게 배정 — ○○ 처리자 칸에 적힘"으로 알려 줍니다.
- 처리 중에는 단추가 잠기고, 실패하면 빨간 토스트와 함께 줄이 원래대로 돌아옵니다.

## 자주 하는 실수·주의
- **업체를 바꾸면 팀 지역이 자동으로 초기화**됩니다. 업체를 바꿨으면 팀 지역을 다시 확인하세요. 지역이 비면 카톡을 보낼 수 없습니다.
- 지역 → 카톡방·일정 시간: A 09:00 · B 12:00 · C 15:00 · D 18:00 · E 21:00(일정리스트·네이버의 시각은 실제 방문 시각이 아니라 팀 구분용입니다).
- 같은 업체·같은 종류를 **10분 안에 다시 접수하면 "중복 접수 확인"** 창이 뜹니다. 정말 다른 건일 때만 진행하세요.
- **사진은 원본으로.** 카톡 PC 미리보기를 복사하면 화질이 아주 낮습니다(240×320 사례). 긴 변 400px 미만은 올라가지 않습니다. 카톡에서 사진을 눌러 크게 연 창에서 복사하세요.
- 기존 거래처는 **순번이 없으면 시트 기입을 건너뜁니다**("퍼스트순 미입력 — 시트 기입 생략"). 신규는 직접 적은 값으로 항상 기입합니다.
- "접수시트 반영 실패 … 10분 내 자동 재시도"가 뜨면 접수는 저장된 것입니다. 다시 접수하지 마세요.
- 일정 등록만 실패하면 접수는 저장됨 — 리스트의 [일정 등록]으로 다시 시도합니다.
- 지원 3종의 카톡방은 아직 정해지지 않았습니다(상세에 "카톡 방 미정"). 저장·시트·달력만 됩니다.
- 관리 탭 테스트 모드가 켜져 있으면 카톡은 테스트방으로만 갑니다. 네이버 캘린더 미러가 꺼져 있으면 [네이버 캘린더]가 실패합니다.

## 숫자가 어떻게 세어지나
- 종류 탭의 숫자 = 그 종류의 **열린 건수**(접수·진행중·보류). 현황판과 같은 숫자입니다.
- 미처리 = 최근 90일 안 접수 중 완료·취소가 아닌 것. 시트 기준 모드에서는 영업·경영·원격·IT를 시트 상태로 셈(위 4번).
- 원격대기 중 **7일이 넘은 것은 미처리에서 뺍니다**.
- 이번 주 완료율 = 이번 주(월~오늘) 접수 중 완료된 것 ÷ 이번 주 접수. 시트 기준 모드에서도 이 비율은 "앱 접수 기준"입니다.
- 복합기 AS 접수는 일정이 완료되면 완료로 맞춰집니다(네이버에서 완료해도 반영).
