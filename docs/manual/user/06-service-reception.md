# 06. 서비스접수

## 무엇을 하는 화면인가
왼쪽 메뉴 **서비스접수**. 고객 전화·카톡·사내 요청으로 들어온 일을 접수하는 화면입니다. 주로 PC에서 씁니다.
임대리스트에서 업체를 고르면 기기 정보가 자동으로 채워지고, 버튼 한 번으로 **접수 저장 · 접수 시트 기입 · 팀 AS 카톡방 · 일정리스트 · 네이버 캘린더**까지 이어집니다.

맨 위 한 줄 **종류 탭**(칸마다 열린 건수)
- 현장: **[복합기 AS] [원격] [IT]**
- 지원: **[경영지원] [운영지원] [영업팀]** — 관리 탭 "서비스접수 지원 3종" 스위치가 켜져 있을 때만 보입니다(2026-10-22 켜져 있음).

왼쪽은 접수 쓰는 곳, 오른쪽 기둥은 **[접수리스트 | 미처리 현황]** 전환입니다.

## 순서대로 쓰는 법 — 복합기 AS · IT
1. 종류 탭에서 **[복합기 AS]** 또는 **[IT]**.
2. 거래처 선택: **기존**이면 검색칸("임대리스트 검색 — 업체명·부서명·자산·시리얼·순번")에 치고 Enter. 결과 줄에서 맞는 기기를 누릅니다. 임대리스트에 없으면 **신규**로 바꾸고 업체명을 직접 적습니다.
   - 결과 줄에 **부서명 회색 알약**(임대리스트의 부서명/현장명)이 붙습니다. 부서명으로 걸린 줄은 알약에 노란 테두리가 있습니다.
   - 검색 순서: 업체명 → 부서명 → 자산 → 기번 → 순번. 숫자만 치면 부서명 단계는 건너뜁니다.
3. 고른 기기 카드에서 순·모델·자산번호·기번·등급·지역·종료일·미수·**부서**를 확인합니다. 틀리면 "⚙️ 자동 입력값 수정"을 펼쳐 고칩니다. 같은 업체에 기기가 여러 대면 노란 줄이 뜨니 자산·기번을 꼭 대조하세요.
4. 접수 내용: 카카오/전화, 임대리스트 순번, 접수분야(복합기만: A/S·점검요청·여분요청·세팅요청·불만·미수·해지방어·직접기재), **접수자 성함·연락처**, 제목(짧게, 복합기 필수), **증상/내용**, **방문 주소**(임대리스트와 다르면 실제 주소로 고침), 팀 지역, 증상 사진(최대 6장, PC는 칸 클릭 후 Ctrl+V), 유상/무상·교체이력·참고사항.
5. 아래 회색 **카톡 보고용 양식**이 자동으로 만들어집니다. 이 글이 그대로 카톡·네이버·일정 내용이 됩니다.
6. 하단 띠의 필수 칩(업체 · 접수자 · 연락처 · 제목 · 내용 · 주소 · 순번)이 모두 초록이면 **[⚡ 전체]** 를 누릅니다 = 접수 + 시트 + 일정 + 네이버 + 카톡 한 번에. 따로 하려면 **[접수] [네이버 캘린더] [카톡 전송]**. 어떤 순서로 눌러도 접수는 한 번만 저장됩니다.
7. 시트를 확인하려면 **[시트 열기]**.

## 순서대로 쓰는 법 — 원격
1. **[원격]** 탭. 거래처를 고르고 접수 내용을 적습니다(방문 주소·카톡 양식 없음).
2. **[접수 (저장+시트)]**. 원격대기로 저장되고 원격 시트에 들어갑니다. 네이버·카톡은 없습니다. **[원격 시트]** 로 확인합니다.
3. 접수리스트에서 그 줄을 펼쳐 처리 시작·끝 시각, 처리자, 추가대수, 처리내용을 적습니다.

## 순서대로 쓰는 법 — 경영지원 · 운영지원 · 영업팀
1. 지원 탭 중 하나를 누릅니다. 맨 위에 **접수자**(로그인한 이름)가 보입니다. 사내 요청이면 요청자를 고릅니다.
2. **거래처 선택**은 복합기와 같은 검색(임대리스트 + 부서명). 없으면 신규 거래처 업체명.
3. **접수유형**(카카오·전화·메일·사내 요청) · **접수분야**(칩 + 직접 입력) · 업체담당자 · 전화번호 · **접수내용** · 특이사항(앱에만 저장) · 처리자(지역 기본값) · 경영지원은 계약서구분(전자·수기) · 예정일.
   - **예정일을 넣으면 부서 달력**(캘린더·일정리스트의 경영·운영·영업 팀 칩)에 올라갑니다. 네이버로는 가지 않습니다.
4. **[접수 저장]**. 저장 → (영업·경영) 시트 기입 → (예정일) 부서 달력. 방금 같은 내용을 저장했으면 "같은 내용을 방금 저장했습니다. 한 건 더 저장할까요?"가 뜹니다.
5. 처리할 때는 접수리스트에서 펼치거나 미처리 현황 카드에서 단추를 누릅니다: **[완료]**(처리내용 선택 → [완료 확정]) · **[내일로]**(다음 영업일) · **[날짜 고르기]** · **[보류]**(다시 누르면 [보류 풀기]) · **[메모]**(영업은 진행 메모 칩도) → [메모 저장]. 상세에서 [수정]·[삭제]도 됩니다.

## 경영·운영·영업 미니 업무공간 (2026-10-24)
지원 3종(경영지원·운영지원·영업팀) 화면에서는 다른 탭을 오가지 않고 이 화면 하나에서 일정 확인·배정·완료까지 합니다. 현장 3종(복합기 AS·원격·IT) 화면은 바뀌지 않았습니다.
1. 지원 탭을 고르면 오른쪽 전환 막대가 **[일정리스트 n | 접수리스트 | 미처리현황 n]** 3칸이 됩니다. 처음엔 일정리스트가 열리고, 마지막에 본 칸을 기억합니다(현장 화면의 기억과 따로).
2. **일정리스트**: 칩 **[금일][익일][예정][미처리]**.
   - 금일 = 예정일이 오늘 · 익일 = 다음 영업일까지(금요일이면 토·일·월) · 예정 = 그 뒤 · **미처리 = 예정일이 지났거나 예정일이 없는 열린 접수**(접수일 오래된 순). 미처리가 있으면 미처리 칩이 먼저 열립니다.
   - 전환 막대의 "일정리스트 n" = 금일(안 끝난 것) + 미처리 수.
   - 카드: 업체 · 분야 · 내용 한 줄 · 예정일 · **처리자 알약**. 알약을 누르면 배정 창(1명)이 뜹니다. 후보 = 부서 기본 처리자 + 관리 탭 인원 명단에서 그 부서(영업팀·경영지원파트·CSS/운영지원파트의 운영지원) 사람. 명단이 비면 이름을 직접 적습니다. 비우고 저장하면 미배정(빨강).
   - 배정은 접수의 처리자 칸을 바꾸고, 영업·경영은 **시트 처리자 칸**도 같이 고칩니다. 예정일이 있으면 부서 달력 메모의 "처리자" 줄도 맞춥니다. 카톡·푸시 알림은 보내지 않습니다.
   - 카드 아래 처리 단추는 위와 같습니다([완료]·[내일로]·[날짜 고르기]·[보류]·[메모]). 완료하면 카드가 빠지고, 내일로·날짜는 맞는 칩으로 옮겨 갑니다.
   - 접수와 연결 안 된 **부서 일정**(부서 달력에 직접 넣은 것)도 날짜 칩에 섞여 보입니다. 누르면 날짜·제목·메모를 고칠 수 있습니다. 삭제·새 일정 추가는 일정 탭 › 부서 칩에서 합니다.
3. **접수리스트**: 예전 목록 그대로(부서 필터가 걸린 상태).
4. **미처리현황**: 홈 미처리 "경영/운영/영업" 탭과 **같은 숫자**입니다(같은 함수로 셈). 앱 접수 줄에는 처리 단추가, 시트에서 온 줄(시트 기준 모드)에는 **[시트에서 열기]** 만 있습니다 — "시트 건 n은 시트에서 처리". 그래서 시트 기준 모드에선 미처리현황 숫자가 일정리스트 미처리보다 클 수 있습니다.
5. 화면 머리(어두운 줄) 오른쪽 **[시트 열기]**: 영업 = 해지방어접수 탭, 경영 = 경영지원접수 탭을 새 창으로 엽니다. 운영지원은 시트가 없어 단추가 없습니다. 폰에서는 "시트"로만 보입니다.
6. 60초마다, 창으로 돌아올 때 다시 읽습니다. 읽기에 실패하면 빨간 줄로 알려 주고 이전 목록은 그대로 둡니다. 배정 저장이 실패하면 카드가 원래대로 돌아가고 빨간 알림이 뜹니다.
- 일정 탭의 경영·운영·영업 칩(부서 달력 달 보기)은 그대로 있습니다. 거기 머리에 "배정·완료는 서비스접수 › 부서 › 일정리스트에서" 안내가 붙었습니다.

## 오른쪽 기둥 — 미처리 현황
1. 오른쪽 위 **[미처리 현황]** 을 누르면 종류별 미처리 칸이 보입니다(홈의 "미처리 접수" 카드를 눌러도 여기로 열림).
2. 숫자 띠: 종류마다 접수·진행중·보류 수, **오늘 접수**, **이번 주 완료율**. 카드는 오래된 순, 경과 3일 이상 노랑·7일 이상 빨강.
3. 현장 3종 카드는 누르면 원래 흐름(접수리스트 펼침, 원격·IT 탭)으로 갑니다. 지원 3종 카드는 카드 아래 처리 단추가 있습니다.
4. **시트 기준 모드**(관리 탭 "서비스접수 미처리 = 시트 상태 기준", 2026-10-22 켜져 있음): 영업·경영·원격·IT 숫자를 **실제 접수 시트의 상태 열**로 셉니다. 처리완료·취소·이관이 아니면 미처리입니다.
   - 시트에서 온 줄에는 "시트" 배지와 상태 글자가 붙고(빈 칸은 "상태 비어 있음"), 누르면 읽기 전용 카드와 **[시트에서 열기]** 가 나옵니다. **처리는 시트에서** 합니다.
   - 90일이 넘은 것은 **"90일 넘음 n"** 칩으로 접혀 있습니다.
   - 시트에서 처리완료로 바꾼 앱 접수는 앱에서도 자동으로 완료됩니다.
   - 시트 읽기가 실패하면 앱 접수 숫자로 보여 주고 안내가 뜹니다. 시트 반영은 1~2분 늦을 수 있습니다.
5. 일정 미처리(지난 날짜·미완료 물류·AS 일정)도 같이 보입니다.

## 자주 하는 실수·주의
- **업체를 바꾸면 팀 지역이 자동으로 초기화**됩니다. 업체를 바꿨으면 팀 지역을 다시 확인하세요. 지역이 비면 카톡을 보낼 수 없습니다.
- 지역 → 카톡방·일정 시간: A 09:00 · B 12:00 · C 15:00 · D 18:00 · E 21:00(일정리스트·네이버의 시각은 실제 방문 시각이 아니라 팀 구분용입니다).
- 같은 업체·같은 종류를 **10분 안에 다시 접수하면 "중복 접수 확인"** 창이 뜹니다. 정말 다른 건일 때만 진행하세요.
- **사진은 원본으로.** 카톡 PC 미리보기를 복사하면 화질이 아주 낮습니다(240×320 사례). 긴 변 400px 미만은 올라가지 않습니다. 카톡에서 사진을 눌러 크게 연 창에서 복사하세요.
- 기존 거래처는 **순번이 없으면 시트 기입을 건너뜁니다**("퍼스트순 미입력 — 시트 기입 생략"). 신규는 직접 적은 값으로 항상 기입합니다.
- "접수시트 반영 실패 … 10분 내 자동 재시도"가 뜨면 접수는 저장된 것입니다. 다시 접수하지 마세요.
- 일정 등록만 실패하면 접수는 저장됨 — 리스트의 [일정 등록]으로 다시 시도합니다.
- 지원 3종의 카톡방은 아직 정해지지 않았습니다(상세에 "카톡 방 미정"). 저장·시트·달력만 됩니다.
- 관리 탭 테스트 모드가 켜져 있으면 카톡은 테스트방으로만 갑니다. 네이버 캘린더 미러가 꺼져 있으면 [네이버 캘린더]가 실패합니다.

## 숫자가 어떻게 세어지나
- 종류 탭의 숫자 = 그 종류의 **열린 건수**(접수·진행중·보류). 현황판과 같은 숫자입니다.
- 미처리 = 최근 90일 안 접수 중 완료·취소가 아닌 것. 시트 기준 모드에서는 영업·경영·원격·IT를 시트 상태로 셈(위 4번).
- 원격대기 중 **7일이 넘은 것은 미처리에서 뺍니다**.
- 이번 주 완료율 = 이번 주(월~오늘) 접수 중 완료된 것 ÷ 이번 주 접수. 시트 기준 모드에서도 이 비율은 "앱 접수 기준"입니다.
- 복합기 AS 접수는 일정이 완료되면 완료로 맞춰집니다(네이버에서 완료해도 반영).
