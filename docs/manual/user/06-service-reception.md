# 06. 서비스접수

## 무엇을 하는 화면인가
왼쪽 메뉴 **서비스접수**. 고객 전화·카톡·사내 요청으로 들어온 일을 접수하는 화면입니다. 주로 PC에서 씁니다.
임대리스트에서 업체를 고르면 기기 정보가 자동으로 채워지고, 버튼 한 번으로 **접수 저장 · 접수 시트 기입 · 팀 AS 카톡방 · 일정리스트 · 네이버 캘린더**까지 이어집니다.

맨 위 한 줄 **종류 탭**(칸마다 열린 건수)
- 현장: **[CS 접수] [원격] [IT]** — 2026-10-25 "복합기 AS" 를 **CS 접수**로 이름만 바꿨습니다(화면 글자만. 저장 값·시트·카톡 양식은 그대로 "복합기 AS", 목록 칩은 "CS")
- 지원: **[경영지원] [운영지원] [전략영업]** — 관리 탭 "서비스접수 지원 3종" 스위치가 켜져 있을 때만 보입니다(2026-10-22 켜져 있음). 화면 이름만 "영업팀" → "전략영업"(2026-10-26) — DB 값·시트·카톡방 키는 영업팀/영업접수 그대로.

왼쪽은 접수 쓰는 곳, 오른쪽 기둥은 **[접수리스트 | 미처리 현황]** 전환입니다. **6종 모두 같은 뼈대**입니다(2026-10-25 밤 사용자 "CS 접수·원격·IT 처럼 똑같이 가자") — 경영·운영·영업을 골랐을 때만 탭 줄 뒤에 **[일정리스트] [달력]** 두 칸이 더 붙습니다.

화면 구조(그림 설명 — 폰은 위에서 아래로, 넓은 PC 는 왼쪽·오른쪽):
- 맨 위: 어두운 머리 줄(작성자·시계) → 종류 칩 **[CS 접수][원격][IT] / [경영지원][운영지원][전략영업]**(칩 숫자 = 미처리 현황과 같은 숫자).
- 왼쪽(폰은 위): 접수 폼. 현장 3종은 거래처 선택 + 접수 내용, 경영·운영·영업은 부서 접수 폼([시트 열기 ↗] 는 [접수 저장] 왼쪽).
- 오른쪽(폰은 아래): 탭 줄 — CS 접수·원격·IT 는 **[접수리스트][미처리 현황 n]** 2칸, 경영·운영·영업은 **[접수리스트][미처리 현황 n][일정리스트 n][달력]** 4칸. 처음 보기는 **접수리스트**(마지막에 본 칸을 기억 — 부서 아닌 종류로 바꾸면 일정리스트·달력 기억은 접수리스트로 보입니다).
- 탭 아래 본문: 접수리스트 = 날짜·기간·종류·상태 칩 + 목록, 미처리 현황 = 6종 공용 현황판 카드(아래 "오른쪽 기둥 — 미처리 현황"), 일정리스트·달력 = 부서 전용(아래 "경영·운영·영업 미니 업무공간").
- **미처리 현황 정렬**(2026-10-25 밤): 종류·물류·90일 넘음 묶음 머리줄(`⌄ ● CS 접수 57건`) 오른쪽 끝의 **[오래된 순 | 최근 순]** 토글(홈 미처리 칸과 같은 선택을 공유). 오래된 순은 예정일 지난 건을 맨 위에 모으고, 최근 순은 순수 접수일 순서이며 예정일이 지난 카드는 빨간 테두리로만 표시됩니다.

## 순서대로 쓰는 법 — CS 접수(옛 복합기 AS) · IT
1. 종류 탭에서 **[CS 접수]** 또는 **[IT]**.
2. 거래처 선택: **기존**이면 검색칸("임대리스트 검색 — 업체명·부서명·자산·시리얼·순번")에 치고 Enter. 결과 줄에서 맞는 기기를 누릅니다. 임대리스트에 없으면 **신규**로 바꾸고 업체명을 직접 적습니다.
   - 결과 줄에 **부서명 회색 알약**(임대리스트의 부서명/현장명)이 붙습니다. 부서명으로 걸린 줄은 알약에 노란 테두리가 있습니다.
   - 검색 순서: 업체명 → 부서명 → 자산 → 기번 → 순번. 숫자만 치면 부서명 단계는 건너뜁니다.
3. 고른 기기 카드에서 순·모델·자산번호·기번·등급·지역·종료일·미수·**부서**를 확인합니다. 틀리면 "⚙️ 자동 입력값 수정"을 펼쳐 고칩니다. 같은 업체에 기기가 여러 대면 노란 줄이 뜨니 자산·기번을 꼭 대조하세요.
4. 접수 내용: 카카오/전화, 임대리스트 순번, 접수분야(복합기만: A/S·점검요청·여분요청·세팅요청·불만·미수·해지방어·직접기재), **접수자 성함·연락처**, 제목(짧게, 복합기 필수), **증상/내용**, **방문 주소**(임대리스트와 다르면 실제 주소로 고침), 팀 지역, 증상 사진(최대 6장, PC는 칸 클릭 후 Ctrl+V), 유상/무상·교체이력·참고사항.
5. 아래 회색 **카톡 보고용 양식**이 자동으로 만들어집니다. 이 글이 그대로 카톡·네이버·일정 내용이 됩니다.
   - **[IT]** 는 2026-10-27부터 IT 방("신)it접수 as")에서 쓰던 카드 모양으로 나갑니다 — 아래 "카톡 글 모양" 절. CS 접수 양식은 그대로입니다.
6. 하단 띠의 필수 칩(업체 · 접수자 · 연락처 · 제목 · 내용 · 주소 · 순번)이 모두 초록이면 **[⚡ 전체]** 를 누릅니다 = 접수 + 시트 + 일정 + 네이버 + 카톡 한 번에. 따로 하려면 **[접수] [네이버 캘린더] [카톡 전송]**. 어떤 순서로 눌러도 접수는 한 번만 저장됩니다.
7. 시트를 확인하려면 **[시트 열기]**.

## 순서대로 쓰는 법 — 원격
1. **[원격]** 탭. 거래처를 고르고 접수 내용을 적습니다(방문 주소·카톡 양식 없음).
2. **[접수 (저장+시트)]**. 원격대기로 저장되고 원격 시트에 들어갑니다. 네이버·카톡은 없습니다. **[원격 시트]** 로 확인합니다.
3. 접수리스트에서 그 줄을 펼쳐 처리 시작·끝 시각, 처리자, 추가대수, 처리내용을 적습니다.

## 순서대로 쓰는 법 — 경영지원 · 운영지원 · 영업팀
1. 지원 탭 중 하나를 누릅니다. 맨 위에 **접수자**(로그인한 이름)가 보입니다. 사내 요청이면 요청자를 고릅니다.
2. **거래처 선택**은 복합기와 같은 검색(임대리스트 + 부서명). 없으면 신규 거래처 업체명.
3. **접수유형**(카카오·전화·메일·사내 요청) · **접수분야**(칩 + 직접 입력) · 업체담당자 · 전화번호 · **접수내용** · 특이사항(앱에만 저장) · 처리자(지역 기본값) · 경영지원은 계약서구분(전자·수기) · 예정일.
   - **예정일을 비우면 접수일(오늘)이 예정일**로 들어가 저장 직후 부서 [일정리스트] 금일과 [달력]에 바로 보입니다(2026-10-25 밤). 다른 날로 잡으려면 날짜를 넣으세요. 접수 수정에서 예정일을 비우면 일정이 삭제되는 동작은 그대로입니다.
   - **예정일을 넣으면 부서 달력**(서비스접수 탭 부서 화면의 일정)에 올라갑니다. 부서 일정·접수는 서비스접수 탭에서 모아 봅니다(2026-10-25, 일정 탭의 경영·운영·영업 칩은 없앰). 네이버로는 가지 않습니다.
   - **사진 첨부(선택, 최대 6장, 2026-10-28)**: 특이사항 아래 사진 칸 — CS 접수 증상 사진과 같은 방식(파일 고르기·Ctrl+V 붙여넣기, 400px 미만은 막고 600px 미만은 확인). 안내 문구 "한조(카운터·소모품 수명) 화면 캡처가 있으면 같이 넣어 주세요 — 없어도 됩니다". 저장하면 사진이 접수의 사진 칸(photos)에 남고, 카톡 카드 접수내용 다음 줄에 `📷 사진 n장 {모아보기 링크}` 가 붙습니다(사진 없으면 줄 없음). 접수리스트 펼침에 썸네일(누르면 크게), 미처리 현황 팝업에 "사진 n장". 시트에는 쓰지 않습니다.
4. **[접수 저장]**. 저장 → (영업·경영) 시트 기입 → (예정일) 부서 달력. 방금 같은 내용을 저장했으면 "같은 내용을 방금 저장했습니다. 한 건 더 저장할까요?"가 뜹니다. 시트 기입이 20초를 넘으면 화면엔 "시트 반영 대기"로 끝나지만 서버는 끝까지 적습니다 — 그 뒤 [완료]·배정·[다시 보내기] 때 앱이 적힌 행 번호를 찾아 접수에 붙이고 시트 처리 칸도 고칩니다(2026-10-25 고침, 그 전엔 시트 갱신을 건너뛰어 시트가 '진행중'에 남았음).
5. 처리할 때는 접수리스트에서 펼치거나 미처리 현황 카드에서 단추를 누릅니다: **[완료]**(처리내용 선택 → [완료 확정]) · **[내일로]**(다음 영업일) · **[날짜 고르기]** · **[보류]**(다시 누르면 [보류 풀기]) · **[메모]**(영업은 진행 메모 칩도) → [메모 저장]. 상세에서 [수정]·[삭제]도 됩니다.
   - **[보류]·[날짜 고르기]는 사유가 필수**입니다(2026-10-27, CS 일정 [익일]과 같은 규칙). 사유 칸이 비면 [보류 확정]·[예정일 저장]이 눌리지 않고, 사유는 방 후속 글의 `사유:` 줄과 메모 기록(`보류 사유:`·`일정 변경 사유:`)에 남습니다(시트에는 쓰지 않음). 보류 풀기는 사유 없이 됩니다. 홈·현황판 [보류](부서 접수 줄)도 사유 창이 뜹니다 — 시트만 있는 줄은 사유 칸이 없어 기존대로 확인창입니다. 이미 완료된 접수를 다시 완료하거나 같은 처리자로 배정해도 방에 다시 알리지 않습니다.
   - **처리하면 그 부서 방에 짧은 후속 글이 갑니다**(2026-10-27, 접수 카드와 같은 방 · 테스트 모드면 테스트방 · 방이 안 정해졌으면 보내지 않음). 첫 줄 `[처리완료]`·`[보류]`·`[배정]`·`[일정 변경]`·`[취소]` + `업체명 · 접수 M/D 접수분야`, 다음 줄에 처리자·처리내용 / 사유 / `10/27(화) → 10/28(수)`. [완료]·[보류](풀기는 안 감)·배정·[내일로]·[날짜 고르기](날짜가 실제로 바뀐 때만)·상세 [처리 저장](상태가 완료·보류·취소로 **바뀐** 때만 — 같은 상태 재저장·처리자/진행 메모만 바꾼 건 안 감)이 보냅니다. [메모]는 보내지 않습니다. 성공 알림 끝에 "카톡 알림 보냄"이 붙고, 전송이 실패해도 처리는 저장되며 빨간 "카톡 알림 실패" 알림만 뜹니다.

## 카톡 글 모양 = 각 방에서 쓰던 양식 (2026-10-27)
저장 때 카톡방에 가는 글이 예전 `[경영지원 접수] ■ 업체 …` 목록에서 **각 방에서 사람이 시트 카드를 복사해 붙이던 글과 같은 배열**로 바뀌었습니다. 사람이 적는 칸(접수분야·업체담당자·전화·접수내용)은 폼 값, 나머지는 고른 **임대리스트 행**에서 자동으로 채웁니다.
- **네 부서 공통**: 머리 줄 바로 다음 **둘째 줄이 `작성자 · 이름`**(AS방 CS 카드와 같은 자리, 처리자가 있으면 `처리자 · 이름` 이 이어지고 사내 요청자는 처리자 뒤 괄호). 예전 맨 끝 "접수자 … · 카카오" 꼬리 줄은 없앴습니다. 카드 칸에 없는 폼 값(예정일·외근요청·계약서구분·진행메모·처리자 없는 사내 요청자)은 **접수내용 다음에 한 줄씩** 붙습니다 — 적은 값은 버리지 않습니다.
- **경영지원**: 경영지원 시트 "접수 카드"(A1:M15) 모양. 머리 줄 `접수분야 · 업체명 · 종료일 · 지역 · 방문주기 · 접수일` + 작성자 + 기번·임대여부·순번·장비소유주·계약일·종료일·납품/교체일·남은개월·기본/평균임대료·기본매수·추가장당·설치업체·유지보수업체·접수자·미수개월·★키맨·방문담당자·사용여부·주소·확장성·기종·접수내용.
- **전략영업**: 머리 줄 `등급 · 접수분야 · 모델명 · 업체명 · 종료일 · 지역 · 접수일`, 빈 줄, `작성자:   이름`, `라벨:   값   /   라벨:   값` 8줄, `🔹 접수내용:`.
- **운영지원**: 경영 카드 틀을 운영 양식에 맞춘 카드(2026-10-27, 말투 글 폐기). 머리 줄 `접수분야 · 업체명 · 종료일 · 지역 · 접수일` + 작성자 + 접수유형/접수분야 · 예정일(요일)/외근요청 · 임대여부/순번 · 계약일/종료일 · 기본임대료/기본매수 · 설치업체/유지보수업체 · 업체담당자/연락처 · ★키맨 · 주소/확장성 · 기종/기번 · 접수내용. 빈 값은 라벨만 남습니다. 예정일을 안 넣으면 예정일 칸이 빈칸(저장 뒤 예정일이 오늘로 채워져도 글은 빈칸 그대로). 특이사항은 글에 싣지 않습니다(앱에만 저장).

- 관리 탭 테스트 모드가 켜져 있으면 카톡은 테스트방으로만 갑니다. 네이버 캘린더 미러가 꺼져 있으면 [네이버 캘린더]가 실패합니다.

## 숫자가 어떻게 세어지나
| 숫자 | 무엇을 세나 | 홈과 같나 |
|---|---|---|
| 종류 칩·현황판 **CS 접수** | 지난 날짜·미완료 AS 일정(매월점검·물류 제외, 최근 180일) | 홈 미처리 "CS 접수"와 같음(같은 로더) |
| 현황판 아래 "일정 없이 열린 접수 n건" | 열린 복합기 AS 접수 중 연결 일정이 하나도 없는 것 | 홈에는 없음(접수리스트에서 처리) |
| 종류 칩·현황판 원격·IT·경영·운영·영업 | 열린 접수(접수·진행중·보류, 최근 90일) · 시트 기준 모드면 시트 상태 | 홈 같은 종류와 같은 기준 |
| 접수리스트 "N건 (앱 n · 시트 m)" | 기간 안 앱 접수 + 앱과 이어지지 않은 시트 행(2026-10-01 이후, CS 는 "기록") | 홈에는 없음(접수리스트만, 2026-10-28) |
| 탭 줄 "미처리 현황 n" | 위 종류 칸 합(지원 3종은 켜져 있을 때만) + 물류 미처리 | — |
| 탭 줄 "일정리스트 n"(부서만) | 그 부서 금일(안 끝난 것) | — |

- 종류 칩의 숫자 = 현황판과 같은 숫자입니다.
- 미처리 = 최근 90일 안 접수 중 완료·취소가 아닌 것. 시트 기준 모드에서는 영업·경영·원격·IT를 시트 상태로 셈(위 4번).
- 원격대기 중 **7일이 넘은 것은 미처리에서 뺍니다**.
- 이번 주 완료율 = 이번 주(월~오늘) 접수 중 완료된 것 ÷ 이번 주 접수. 시트 기준 모드에서도 이 비율은 "앱 접수 기준"입니다.
- 복합기 AS 접수는 일정이 완료되면 완료로 맞춰집니다(네이버에서 완료해도 반영).
