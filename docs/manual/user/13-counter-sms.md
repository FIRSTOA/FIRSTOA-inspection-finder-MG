# 13. 카운터 문자전송

## 무엇을 하는 화면인가
왼쪽 메뉴 "고객·홍보" 묶음의 **카운터 문자전송**. 마감 때 고객에게 "카운터 사진 한 장 보내 주세요" 문자를 보내는 화면입니다.
- 관리부(또는 아무나)가 팀 마감 목록을 **한 번 올리면** 팀원 모두가 같은 목록을 보고 한 업체씩 보냅니다.
- 문자는 회사 서버가 아니라 **내 폰 문자앱**에서 나갑니다. 앱은 문구를 만들어 문자앱을 열어 주고, "보냈다(✓)"를 팀에 공유합니다.
- 누가·언제 보냈는지 전 직원이 보므로 **같은 업체에 두 번 보내지 않게** 됩니다.

## 순서대로 쓰는 법 — 팀원
1. 화면을 열면 **★ 내 팀** 목록이 자동으로 열립니다. 다른 팀을 도와줄 때는 팀 알약을 바꿉니다.
2. 등급군 탭(S·NN·N급 / V·SS급)을 고릅니다. 등급군마다 인사말이 다릅니다.
3. 업체 카드(✉️)를 누르면 **문자 전송 대상 확인**과 **전송 문구 미리보기**가 나옵니다. 기기가 여러 대면 "총 n대", 같은 담당자의 여러 지점은 한 카드로 묶입니다.
4. 보내기를 누르면 번호·문구가 채워진 문자앱이 열립니다. 문자앱에서 실제로 보냅니다.
5. 카드에 **✓ 보냄**(누가·언제)이 찍힙니다. **문자앱에서 실제로 안 보냈으면 바로 [전송 취소]**.
6. 고객이 카운터 사진을 보내 주면 카드의 **[카운터 전송]**(📷) → 사진첩에서 사진 선택 → 확인창에서 글·방 확인 → 보내기. 마감 카톡방에 업체명·기종·시리얼·자산기번·주소·전송자와 사진이 올라가고 카드가 **"완료 · 카운터 사진"**으로 바뀝니다.
   - 📷 단추는 시험 중인 팀 카드에만 보입니다(관리 설정에서 정한 팀) **(확인 필요: 지금 열린 팀)**.
7. 사진 없이 끝난 업체는 **[완료]**. 잘못 눌렀으면 **[완료 취소]**.

## 순서대로 쓰는 법 — 목록 올리기(관리부·담당)
1. **마감 목록 올리기** → 팀을 고르고 제목(비우면 "○월 마감").
2. 카톡 마감 목록을 그대로 붙여넣고 **[🔍 변환 미리보기]** → 인식 결과에서 업체명(등급)·연락처만 고칩니다.
3. **올리는 방식** 을 고릅니다.
   - **목록 맞추기 — 빠진 업체 자동 완료 (권장)**: 관리부가 끝난 업체를 빼고 다시 올린 목록일 때. 이번 목록에 없는 열린 업체는 자동 완료, 새 업체는 추가, 이미 보낸 표시는 유지.
   - **추가만 (빠진 업체 그대로)**: 일부 구역·추가분만 받은 목록일 때.
   - **새 목록으로 교체**: 달이 바뀐 목록. 지금 목록은 기록으로 남습니다.
4. 등록. 관리부 목록이 마감 카톡방에 올라오면 자동으로 반영되기도 합니다 **(확인 필요: 자동 반영이 켜진 팀·방)**.

## 자주 하는 실수·주의
- ✓는 **문자앱을 연 순간** 찍힙니다. 실제로 안 보냈으면 [전송 취소]를 꼭 누르세요. 안 그러면 다른 사람도 그 업체를 건너뜁니다.
- **🚫 보내지 말 것**(연락 금지 번호)이 붙은 업체·번호는 보내지 마세요. **⭐ 새 담당**은 바뀐 담당자 번호입니다. 전체 기록은 규칙 보기 단추에서 봅니다. 통합 검색 상태 카드에도 연락금지가 빨갛게 뜹니다(09장).
- [목록 삭제]는 그 목록과 ✓ 기록을 **전 직원 화면에서** 지웁니다.
- 마감 카톡방이 관리 탭 카톡방 매핑에 없으면 "아직 등록된 방이 없어 카운터 전송이 막혀 있습니다."가 뜹니다(14장).
- 카톡 사진 전송도 **밤 22:00~08:00에는 대기**했다가 아침에 나갑니다(00장).
- 문구는 **문구 설정**(🌍 지역 프로필)에서 지역별 인사말·기종별 안내를 고칩니다. [기본값으로]로 되돌립니다.

## 숫자가 어떻게 세어지나
- 목록 머리 "n/m 전송" = ✓ 찍힌 카드 수 / 전체 카드 수.
- 등급군 탭 숫자 = 업체 수.
- 완료된 카드는 접혀 있어 열린 업체만 보입니다.
- 조회 › 기록 조회 › 고객 연락 › **마감 카운터 문자** 에서 지난 기록을 봅니다(08장).
