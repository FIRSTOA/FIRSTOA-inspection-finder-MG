# 13. 카운터 문자전송

## 무엇을 하는 화면인가
왼쪽 메뉴 "고객·홍보" 묶음의 **카운터 문자전송**. 마감 때 고객에게 "카운터 사진 한 장 보내 주세요" 문자를 보내는 화면입니다.
- 관리부(또는 아무나)가 팀 마감 목록을 **한 번 올리면** 팀원 모두가 같은 목록을 보고 한 업체씩 보냅니다.
- 문자는 회사 서버가 아니라 **내 폰 문자앱**에서 나갑니다. 앱은 문구를 만들어 문자앱을 열어 주고, "보냈다(✓)"를 팀에 공유합니다.
- 누가·언제 보냈는지 전 직원이 보므로 **같은 업체에 두 번 보내지 않게** 됩니다.

## 화면 한눈에 (2026-10-24 단순화)
- **머리 한 줄**: `10월 마감 · 24곳 · 보냄 4 · 완료 0 · 신규 3`. 숫자는 두 등급을 합친 값입니다. **[신규 n]**을 누르면 새로 추가된 업체만 보입니다(다시 누르면 전체).
- **↻(새로고침)** 과 **⋯** — ⋯ 안에 [목록 전체 삭제]가 있습니다.
- **이 화면은?** — 처음엔 펼쳐져 있고, 접으면 그 기기에서는 접힌 채로 기억합니다. 3줄 사용법과 배지 뜻이 있습니다.
- **변경 이력 n** — 접혀 있습니다. 한 줄 = 목록이 바뀐 한 번: `10-23 13:19 자동 · 신규 1 · 중복 2 · 목록에 없는 열린 곳 17`(한국 시각). **[보기]**를 누르면 그 줄의 업체명이 칩으로 펼쳐집니다(신규·중복/유지·빠져서 완료·목록에 없는 열린 곳·삭제).
  - "목록에 없는 열린 곳"은 관리부 최신 목록에 없는데 아직 열린 카드입니다. 관리부가 끝낸 곳이면 그 카드 ⋯ 에서 [완료].
  - 예전 맨 위 초록 "⚡ 관리부 목록 자동 반영" 블록은 같은 내용이라 없앴습니다. **노란 "📥 자동으로 못 넣은 목록"** 은 사람이 할 일이 있어 그대로 있습니다([직접 넣기]·[무시]).
- **등급 탭**: **일반 S·NN·N** / **우수 V·SS**. 등급군마다 인사말이 다릅니다. 탭 아래 칩: [처리 순 | 추가된 날짜순] · [전체 | 신규 n].

### 신규란?
이번 달 목록이 **처음 생긴 뒤 2분 넘게 지나** 자동(관리부 목록 자동 반영)이나 손(추가·맞추기)으로 들어온 업체입니다. 카드에 초록 테두리 **신규 10/23**(추가된 날)이 붙습니다. 처음 올린 목록에 있던 업체, 추가 시각 기록이 없는 옛 카드는 신규가 아닙니다. 새 달 목록이 생기면 다시 0부터 셉니다.

### 카드 한 장
| 줄 | 내용 |
|---|---|
| 1줄 | 업체명 · **신규 MM/DD**(해당 시) · 상태 알약 — 안 보냄은 없음 / **보냄**(초록) / **완료**(남색) |
| 2줄 | `2대 · 010-…`(지점 여러 곳이면 "지점 n곳 통합") · 주의 배지 1개 · CMS·⭐·🚫·이름 유사 |
| 3줄 | `추가 10/23 박지은 · 문자 10/24 10:12 김OO · 완료(또는 📷 사진 전송) …` |
| 단추 | 주 단추 1개 + **⋯** |

**주의 배지(1개만, 위가 먼저)**: 완료 뒤 다시 올라옴(빨강) > 보낸 뒤 다시 올라옴(주황) > 다시 올라옴 n회(회색). 배지에 손가락을 오래 대거나 마우스를 올리면 올라온 날짜가 다 보입니다.
기타 배지: **CMS n일** = 따로 오는 CMS 마감(숫자 = 결제일) · **⭐** 새 담당 · **🚫** 막은 번호(🚫 전부 = 모든 번호 막힘) · **이름 유사** = 업체명이 비슷하게만 맞는 기록.

**단추 위치**
| 카드 상태 | 주 단추 | ⋯ 안 |
|---|---|---|
| 안 보냄 | [문자 보내기] | [📷 카운터 전송](사진 팀만) · [이 업체 삭제] |
| 보냄 | 사진 팀: [📷 카운터 전송] / 그 밖: [완료] | [완료](사진 팀) · [전송 취소] · [이 업체 삭제] |
| 완료 | 없음 | [완료 취소](문자 보낸 카드만) · [이 업체 삭제] |

카드 자체를 눌러도 예전처럼 문자 전송 창이 열립니다. 삭제는 확인창이 한 번 더 뜹니다.

## 순서대로 쓰는 법 — 팀원
1. 화면을 열면 **내 팀** 목록이 자동으로 열립니다. 다른 팀을 도와줄 때는 팀 알약을 바꿉니다.
2. 등급 탭(일반 / 우수)을 고릅니다. 새로 들어온 곳만 보려면 머리의 **[신규 n]**.
3. 카드의 **[문자 보내기]**(또는 카드 누름) → **문자 전송 대상 확인**과 **전송 문구 미리보기**. 기기가 여러 대면 "총 n대", 같은 담당자의 여러 지점은 한 카드로 묶입니다.
4. 보내기를 누르면 번호·문구가 채워진 문자앱이 열립니다. 문자앱에서 실제로 보냅니다.
5. 카드에 **보냄**(누가·언제)이 찍힙니다. **문자앱에서 실제로 안 보냈으면 바로 ⋯ → [전송 취소]**.
6. 고객이 카운터 사진을 보내 주면 **[📷 카운터 전송]** → 사진첩에서 사진 선택 → 확인창에서 글·방 확인 → 보내기. 마감 카톡방에 업체명·기종·시리얼·자산기번·주소·전송자와 사진이 올라가고 카드가 **완료**(3줄에 "📷 사진 전송")로 바뀝니다.
   - 📷 단추는 시험 중인 팀 카드에만 보입니다(관리 설정 COUNTER_PHOTO_TEAMS) **(확인 필요: 지금 열린 팀)**.
7. 사진 없이 끝난 업체는 **[완료]**(사진 팀이면 ⋯ 안). 잘못 눌렀으면 ⋯ → **[완료 취소]**.

## 순서대로 쓰는 법 — 목록 올리기(관리부·담당)
1. **마감 목록 올리기** → 팀을 고르고 제목(비우면 "○월 마감").
2. 카톡 마감 목록을 그대로 붙여넣고 **[🔍 변환 미리보기]** → 인식 결과에서 업체명(등급)·연락처만 고칩니다.
3. **올리는 방식** 을 고릅니다.
   - **목록 맞추기 — 빠진 업체 자동 완료 (권장)**: 관리부가 끝난 업체를 빼고 다시 올린 목록일 때. 이번 목록에 없는 열린 업체는 자동 완료, 새 업체는 추가, 이미 보낸 표시는 유지.
   - **추가만 (빠진 업체 그대로)**: 일부 구역·추가분만 받은 목록일 때.
   - **새 목록으로 교체**: 달이 바뀐 목록. 지금 목록은 기록으로 남습니다.
4. 등록. 관리부 목록이 마감 카톡방에 올라오면 자동으로 반영되기도 합니다 **(확인 필요: 자동 반영이 켜진 팀·방)**.

## 자주 하는 실수·주의
- ✓는 **문자앱을 연 순간** 찍힙니다. 실제로 안 보냈으면 [전송 취소]를 꼭 누르세요. 안 그러면 다른 사람도 그 업체를 건너뜁니다.
- **🚫 보내지 말 것**(연락 금지 번호)이 붙은 업체·번호는 보내지 마세요. **⭐ 새 담당**은 바뀐 담당자 번호입니다. 전체 기록은 규칙 보기 단추에서 봅니다. 통합 검색 상태 카드에도 연락금지가 빨갛게 뜹니다(09장).
- 머리 ⋯ → [목록 전체 삭제]는 그 목록과 보냄·완료 기록을 **전 직원 화면에서** 지웁니다. 한 업체만 지우려면 카드 ⋯ → [이 업체 삭제].
- 마감 카톡방이 관리 탭 카톡방 매핑에 없으면 "아직 등록된 방이 없어 카운터 전송이 막혀 있습니다."가 뜹니다(14장).
- 카톡 사진 전송도 **밤 22:00~08:00에는 대기**했다가 아침에 나갑니다(00장).
- 문구는 **문구 설정**(🌍 지역 프로필)에서 지역별 인사말·기종별 안내를 고칩니다. [기본값으로]로 되돌립니다.

## 숫자가 어떻게 세어지나
- 머리 줄 "n곳 · 보냄 · 완료 · 신규" = 두 등급 합. 보냄 = 문자 보낸 표시가 있는 카드(완료된 것 포함), 완료 = 완료 표시 카드, 신규 = 위 "신규란?" 기준. 진행 막대 = 보냄 / 전체.
- 등급 탭 숫자 = 그 등급 업체 수.
- 완료된 카드는 접혀 있어 열린 업체만 보입니다.
- 조회 › 기록 조회 › 고객 연락 › **마감 카운터 문자** 에서 지난 기록을 봅니다(08장).
