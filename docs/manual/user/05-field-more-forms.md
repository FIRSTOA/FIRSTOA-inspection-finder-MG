# 05. FIELD — 더보기 양식 (담당자/주소 변경 · 불만 · 미수 · 초과조정 · 재계약 · 교체양식 · 칭찬)

## 무엇을 하는 화면인가
FIELD 맨 위 **[더보기 ▾]** 를 누르면 7가지 양식이 나옵니다. 고르면 탭 글자가 그 양식 이름(담당자/주소 변경은 "담당자/주소")으로 바뀝니다.

| 양식 | 하는 일 | 보내면 어디로(기본, 관리 탭 매핑이 우선) |
|---|---|---|
| 담당자/주소 변경 | 거래처 담당자·주소 변경 전·후와 명함 사진 | 신)담당자/명의/주소변경등 특이사항 방 + 시트 |
| 불만 | 불만 내용과 방문 처리결과 | A·B → 신)AB불만고객 / C·D → 신)CD불만고객방 + 불만 시트. E팀 방은 매핑 없음 **(확인 필요)** |
| 미수 | **CS 방문이력 작성기**(법무 기준) | 지역 미수방(A~D). **E는 방이 없어 저장만** |
| 초과조정 | 초과 사용량 조정 상담 | 지역 "…/초과사용 계약종료체크" 방 |
| 재계약 | 계약 종료 예정 거래처 상담 | 초과조정과 같은 지역 방 |
| 교체양식 | 퍼스트전산 채널용 교체 양식 | **카톡 안 나감 — [복사]만** |
| 칭찬 | 고객 칭찬 접수 | **카톡 안 나감 — 칭찬 시트에만 기입** |

## 순서대로 쓰는 법 — 담당자/주소 변경 · 불만 · 초과조정
1. 먼저 점검·AS 탭에서 그 업체 양식을 🔍로 불러 둡니다.
2. 더보기 → 양식을 고르고, 맨 위 **불러오기 [점검] [AS]** 로 업체·지역·등급·키맨(담당자 변경은 기존 담당자)을 가져옵니다.
3. 칩을 누르거나 **직접입력** 으로 칸을 채웁니다(칩을 다시 누르면 해제).
4. 담당자 변경은 새 담당자 명함 사진을 [사진]으로 붙입니다.
5. **[보내기]**. 시트로 가는 양식은 옆 **[📄 시트 열기]** 로 확인합니다.

## 순서대로 쓰는 법 — 재계약 (다음 확인일 · 일정 만들기)
1. 더보기 → **재계약**. 불러오기 후 ■ 기본정보 · ■ 갱신 · ■ 고객 상황 · ■ 현재 계약 조건 · ■ 제안 내용 · ■ 원인분석 · ■ 실행전략 · ■ 다음 액션 · ■ 마무리를 채웁니다.
2. **다음 확인일**(비워도 됨) 칸을 누르면 달력 시트가 열립니다. 빠른 칩(익일 · +3일 · +1주 · +2주 · +1달 · +3달)이나 달력에서 고르고 **[이 날짜로]**. 다음 확인일은 **날짜로만** 받습니다 — [미정·글로 쓰기]는 이 칸에 없습니다(2026-10-27).
   - 표에는 `2026-10-29` 꼴로, 카톡에는 `2026-10-29(목)` 꼴로 들어갑니다.
3. **[보내기]**. 다음 확인일은 비워도 보내집니다(그때는 일정을 만들지 않음). 날짜가 아닌 글자가 들어 있으면 **"전송 실패: 다음 확인일은 날짜로 고르세요"** 가 뜹니다.
4. 보내기가 성공하면 묻지 않고 **바로 일정을 만듭니다**(2026-10-27). 팀(양식 지역 → 없으면 작성자 팀)·제목("[재계약 확인] 업체명")·장소(임대리스트 주소)·내용(요약 + 카톡 원문)·담당(후속담당자)은 예전 창의 기본값 그대로입니다.
   - **일정리스트 · 캘린더 · 네이버 캘린더** 세 곳에 1건이 들어가고(유형 AS, 팀 시간대) 알림 **"재계약 확인 일정 11/15 만들었습니다 [취소]"** 가 10초 동안 뜹니다.
   - 잘못 만들었으면 10초 안에 **[취소]** — 일정리스트·캘린더·네이버에서 그 일정을 지웁니다. 네이버 삭제만 실패하면 "네이버 캘린더에서 직접 지워 주세요"가 뜹니다.
5. 아래 경우에는 예전처럼 **"다음 확인일로 일정 만들까요?"** 창이 떠서 사람이 정합니다.
   - 같은 업체에 열린 재계약 일정이 이미 있으면 자동으로 만들지 않고 **"이미 재계약 일정이 있습니다"** → **[그 일정을 M/D로 옮기기]** / **[새로 하나 더]** / **[취소]**.
   - 자동 만들기가 실패하면(팀을 알 수 없음·신호 약함 등) "일정 자동 만들기 실패" 알림과 함께 창이 뜹니다. 팀·제목을 확인하고 **[일정 만들기]** 또는 **[안 만들기]**. 창을 닫지 않고 화면을 떠나면 24시간 안에 다시 들어올 때 또 묻습니다.
   - 테스트 모드에서는 자동으로 만들지 않고 늘 창으로 묻습니다(제목에 [테스트], 네이버에는 안 올림).
   - "네이버 등록만 실패했습니다"가 뜨면 일정리스트·캘린더에는 들어간 것입니다. **[네이버 다시 시도]**(여러 번 눌러도 1건) 또는 **[나중에]**.

## 순서대로 쓰는 법 — 미수 (CS 방문이력 작성기)
법무팀 기준에 맞춰 버튼만 눌러도 **반려되지 않는 문장**이 만들어지는 7단계 작성기입니다. 폰에서 쓰기 좋게 되어 있습니다.
1. **업체·차수**: "우리 팀 미수 목록"에서 업체를 고릅니다(목록에 없으면 "다른 업체 찾기"에서 거래처명·거래처코드로). 지난 방문 수와 마지막 차수를 보고 **방문 차수**(1차 안내 / 2차 경고)를 정합니다.
2. **방문 일시·응대자**: 방문 일시(기본 지금), 응대자 이름 + 직위, 대표자 본인 여부, 대표자 연락처(확보/거부/모름). 아무도 없으면 "아무도 없음".
3. **운영 여부**: 영업중 / 문 잠김. 문 잠김이면 우편물·간판·옆 가게 진술 중 근거 1개 이상.
4. **독촉 내용**: 전달 방법(구두 안내 · 안내문 봉함 전달 · 봉함 투입)과 상대 답변.
5. **기기 반환 요구**: 누구에게 · 답변 · 반환 방법. **2차 경고면 필수**, 1차면 선택.
6. **사진 4칸**: ① 외부(간판 + 호수) ② 출입문 ③ 기기 + S/N ④ 안내문. 칸마다 [찍기]/[앨범], 못 찍었으면 [촬영 불가] + 사유.
7. **현장 판단**: 계속 독촉 / 철수 / 소송이관 + 사유 한 줄.
8. 아래 **보낼 문장 미리보기**를 봅니다. "빨간 줄은 이대로 보내면 법무팀에서 반려됩니다." 칩 ✓(됨) · ✗(막힘) · !(확인)을 확인합니다.
9. **"현장 4원칙(시간·채무 고지 대상·봉함·잠긴 곳 안 열기)을 지켰습니다."** 에 체크하고 **[저장하고 보내기]**.
10. 나중에 빠진 것을 채우려면 조회 › 미수 › [방문 이력]에서 그 방문의 **[보완 기록 쓰기]** (08장). 원 기록을 복사한 새 초안이 FIELD 미수 작성기에 열립니다.

## 순서대로 쓰는 법 — 교체양식 · 칭찬
- **교체양식**: 12개 칸(캘린더 글머리 · 날짜 · 유입경로 · 영업담당 · 수리배정 담당 · 교체/철수사유 · 상호 · 성함 · 연락처 · 주소 · 장비소유주 · 물품)을 채우고 **[복사]** → 퍼스트전산 채널에 붙여넣기. 전송 단추 자리에는 "전송 불가 · 복사 전용"이 보입니다.
- **칭찬**: 날짜 · 등급 · **거래처명** · 담당자 · 연락처 · **칭찬이유**(칩: AS 서비스 만족 · 점검 서비스 만족 · 친절한 응대 · 빠른 문제 해결 · 상담 만족) · 간단 → **[보내기]**. 거래처명과 칭찬이유가 있어야 눌립니다.

## 자주 하는 실수·주의
- **미수 방문 원칙**: 08시~21시 사이에만 방문·연락(밖이면 사유를 적어야 하고 기록에 남음). 채무 사실·금액은 대표자·담당자에게만. 안내문은 반드시 봉함. 잠긴 곳은 절대 열지 않기.
- 미수 응대자를 **"직원"만 적으면 반려**됩니다. 이름까지 적으세요.
- 미수 작성기는 쓰다 끊겨도 초안이 폰에 남습니다. 다시 열면 이어 씁니다. 같은 기록을 두 번 눌러도 1건만 저장됩니다.
- **E팀 미수는 카톡방이 없어 저장만 됩니다**(화면에 "저장만 됩니다" 안내). 예전처럼 테스트방으로 가지 않습니다.
- 옛 미수 양식으로 보낸 기록은 매일 밤 시트로 표가 통째 바뀌면서 앱에 남지 않았습니다. 새 작성기 기록은 따로 보관되어 사라지지 않습니다.
- 담당자/주소 변경·불만·초과조정·재계약은 **보내기에 성공하면 양식·사진이 비워집니다**(2026-10-22). 실패하면 그대로 남으니 고쳐서 다시 보내면 됩니다. 재계약의 일정 자동 만들기와 "일정 만들까요?" 창은 비워진 뒤에도 정상으로 동작합니다. 교체양식은 전송이 없어 [초기화]로 지웁니다.
- 칭찬은 보내면 비워집니다(날짜만 유지). "시트 반영 대기"는 저장은 된 것이니 다시 보내지 마세요. "같은 내용의 칭찬이 이미 접수돼 있어요"는 중복입니다.
- 토스트의 "카카오 전송 보류"는 관리 설정상 카톡이 꺼진 상태입니다(04장 참고).

## 숫자가 어떻게 세어지나
- 보내기 성공 때 방문 기록이 생겨 주간현황판 [내 현황]의 미수·불만·재계약·초과조정 칸에 1씩 들어갑니다(10장).
- 순위표: 재계약·불만은 **서로 다른 업체 수(곳)**, 미수·초과조정·담당자 변경은 **건수**로 셉니다.
- 조회 › 미수 [방문 이력]의 업체 상태 칩: 소송이관 준비 완료 > 보완 필요 > 반환요구 기록 있음 > 2차 완료 > 1차만 > 방문 기록 없음(위가 우선).
- 교체양식은 [복사]할 때 운영현황에 교체 1건으로 기록됩니다.
