# 14. 관리 탭 (스위치와 설정)

## 무엇을 하는 화면인가
왼쪽 메뉴 맨 아래쪽 **관리**. 값을 **바꾸는** 화면을 모아 둔 곳입니다. 여기서 바꾸면 **회사 전체**에 바로 적용됩니다. 팀장·관리자만 만지세요.
맨 위 짙은 상태줄은 어느 탭에 있든 지금 상태(카톡 전송·시트 동기화 켜짐, 테스트 모드, 최근 시트 실패 수)를 보여 줍니다.

탭
| 탭 | 하는 일 |
|---|---|
| **인원** | 인원 관리(회사 전체 명단, 팀, 퇴사자). 작성자 고르기·순위표의 팀이 이 명단을 따릅니다 |
| **담당자·주소 변경** | FIELD 담당자/주소 변경으로 들어온 이력 |
| **동기화 현황** | 시트·카톡 수집 등 동기화가 잘 도는지, "동기화는 어디서 도나요?" 설명 |
| **전송·카톡방** | 전송·연동 스위치, 테스트 카톡방 이름, 네이버 캘린더 ID, 홈 KPI 목표(KPI_TARGETS), 카톡방 매핑, 카톡 수집 상태·수집 방 매핑, 시트 기입 최근 작업, 카톡 발송 현황 · 방별, 거래처 코드 미매칭 확정 |
| **알림** | 푸시 알림(종류별 받기 설정) |

| **시트 테스트 모드** (위험) | 시트 기입이 테스트 탭으로만 | 꺼짐 |

## 순서대로 쓰는 법
1. 관리 → 원하는 탭.
2. 스위치는 눌러서 켜고 끕니다. **(위험)** 표시가 있는 스위치는 회사 전체 전송·접속을 바꿉니다. 켜기 전에 팀장과 확인하세요.
3. 테스트 모드가 켜져 있으면 화면 위에 "테스트 모드가 켜져 있습니다 — 전송·기입이 실제 방/탭으로 가지 않습니다." 노란 띠가 뜹니다. **테스트가 끝나면 반드시 끄세요.**
4. **카톡방 매핑**: 양식 종류(점검·AS·미수·불만·재계약·초과조정·자가·부품·마감 등) × 지역(A~E, * 공통)마다 실제 카톡방 이름을 정합니다. 방 이름은 카톡방 이름과 **한 글자도 다르지 않게** 적어야 합니다. 새 방을 추가할 때는 운영 담당에게 맡기는 것이 안전합니다(ops/ 문서의 "방 추가" 절차).
5. **카톡 발송 현황 · 방별**: 방마다 마지막 배달 시각·밀린 글·지연 여부. 홈 실시간 전송 현황판과 같은 재료입니다.
6. **시트 기입 최근 작업**: 실패한 시트 기입을 보고 다시 실행합니다.
7. **홈 KPI 목표 (KPI_TARGETS)** — 전송·연동 스위치 묶음 맨 아래 **양식**. 홈 KPI 현황판의 목표 숫자와 [주요 목표]에 넣을 지표를 바꿉니다(2026-10-24 양식형, JSON 몰라도 됨).
   - 지표마다 한 줄: 지표명 · **목표 숫자 칸**(인당 주 / 인당 영업일 / 파트당 월 / 인당 월 / 전체 월·분기 / 비율 % — 지표에 맞는 칸만 보임) · **주요 목표** 체크. 각 숫자 칸 아래에 **기본 n** 이 보이고, 칸을 비우면 기본값입니다. 예: 오버홀(K33)을 인당 주 2→1 로 바꾸려면 숫자 칸에 1 을 넣고 [저장].
   - **추가 휴일**: 날짜를 골라 [추가], ✕ 로 삭제. 주말·공휴일은 자동으로 빠지고, 회사 휴무일만 여기에 넣습니다(영업일 계산에서 제외).
   - 틀린 값(음수·숫자 아님)은 칸이 **빨갛게** 되고 [저장]이 막힙니다.
   - [저장] 뒤 **홈 달성표는 다음 갱신(최대 5분, 또는 위젯 [다시 불러오기])** 때 반영됩니다. 기본값과 같은 칸은 저장하지 않으므로, 나중에 기본 목표가 코드에서 바뀌면 따라갑니다.
   - **고급: JSON 직접 편집**(접이식, 개발자용): 같은 값을 JSON 으로 직접 고칩니다. 예 `{"K10":{"perTeamMonth":3},"K8":{"main":true},"holidays":["2026-12-31"]}`. 칸 이름: `perPersonWeek`·`perPersonBizDay`·`perTeamMonth`·`perPersonMonth`·`monthTotal`·`quarterTotal`·`value`·`main`·`holidays`. 빨강 "JSON 이 아닙니다"는 저장 불가, 노랑 "무시한 값"은 확인 후 저장(그 값은 홈에서 무시). KPI 번호: IT 실습 K21 · IT 퀴즈 K34 · 오버홀 K33.
   - 기본 목표(4분기 OKR·팀장 지시): PC확장성 인당 영업일 1 · 초과사용 제안 파트 월 2 · 블로그 인당 주 2 · 오버홀 인당 주 2 · IT 실습 주 1 · IT 퀴즈 주 2.

## 인원 호칭(직책)과 홈 오버홀 KPI (2026-10-24)
- 오버홀 점수의 원본은 **구글 시트(오버홀 리스트)** 의 "리스트(26년)" 탭입니다(열: 담당자·날짜·오버홀포인트·수리포인트). 탭 이름이 바뀌면 관리 탭 설정 **OVERHAUL_SHEET_TAB** 에 새 탭 이름을 적으세요(비우면 "리스트(26년)"). 시트는 "링크 있는 사람 보기"여야 읽힙니다.
- **인원 탭**에서 각 사람의 **호칭**(팀장 / 파트장 / 부파트장)을 입력해 둡니다. 홈 **오버홀(K33)** 은 이 호칭이 있는 사람을 **집계와 목표 인원 모두에서 뺍니다**(팀장·파트장·부파트장). 그래서 호칭이 비어 있으면 그 사람이 오버홀 목표 인원에 그대로 들어가 목표가 커집니다.
- 다른 KPI 는 호칭과 상관없이 **팀장 팀 소속만** 뺍니다(예전 그대로).
- **할 일**: 2026-10-24 기준 호칭이 입력된 사람은 부파트장 3명·팀장 1명뿐입니다. **파트장 4명의 호칭이 비어 있어** 입력이 필요합니다(코드가 아니라 데이터). 호칭은 정확히 "팀장"·"파트장"·"부파트장" 글자여야 합니다(앞뒤 공백은 무시).

## 자주 하는 실수·주의
- 매핑에 없는 지역·종류는 카톡이 나가지 않습니다(2026-10-22 기준 **미수 E, 불만 E는 방 없음** → 저장만). 지원 3종(경영·운영·영업) 접수 방도 아직 없습니다.
- 그룹웨어 로그인 필수를 끄면 그룹웨어 관련 화면이 모두 숨고 예전처럼 작성자를 직접 고릅니다.
- 네이버 캘린더 등록이 갑자기 안 되면(토큰 만료·비밀번호 변경) 이 탭의 안내대로 연동 계정을 다시 연결해야 합니다. 직접 하기 어려우면 운영 담당에게.
- 여기서 바꾼 값은 다른 직원 화면에 바로(또는 다음 새로고침 때) 적용됩니다.
- KPI_TARGETS 를 잘못 적어도 홈은 멈추지 않습니다 — 틀린 칸만 기본값으로 세고 홈 KPI 현황판 위에 노란 줄로 알립니다.

## 숫자가 어떻게 세어지나
- 상태줄 "시트 실패" = 최근 시트 기입 작업 20건 중 실패(또는 오류가 붙은 대기) 수.
- 인원 수 = 재직(활성) 인원 수. 홈 "CS 재직 N명"과 같은 재료.
