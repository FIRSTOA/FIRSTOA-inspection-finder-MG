## IT 학습·처리이력 — 퀴즈 기록·실습 기록 (2026-10-24)
IT파트 시트는 **읽기 전용**(남의 데이터)이라 건드리지 않습니다. 대신 FIELD 쪽에 **내가 푼 퀴즈와 실습 기록만** 따로 남겨 홈 KPI 에 반영합니다.

### 기술 퀴즈 — 완료하면 자동 기록
1. 먼저 **작성자를 선택**해 두세요(기기에서 고른 작성자). 작성자가 없으면 기록되지 않고 완료 화면에 "작성자를 선택하면 퀴즈 기록이 KPI 에 잡힙니다"가 나옵니다.
2. 퀴즈를 끝까지 풀어 완료 화면(점수 n/n)에 닿으면 **자동으로 1회 기록**됩니다(난이도·문항 수·맞힌 수·날짜 KST). 따로 누를 것이 없고, 같은 완료 화면을 다시 그려도 중복 저장되지 않습니다. [다시 풀기]로 새로 풀어 끝내면 또 1회입니다.
3. 완료 화면 점수 아래 작은 글씨로 결과를 알려 줍니다: "퀴즈 기록이 홈 KPI 에 반영됩니다"(저장됨) · **"기록 표 준비 중"**(SQL 실행 전 — 저장 안 됨) · "퀴즈 기록을 저장하지 못했습니다"(네트워크 등, 다시 시도 가능).

### [실습 기록] 양식 (IT 학습 탭 상단, 눌러서 펼침)
1. **제목**(필수, 80자까지, 예: 복합기 정착기 분해 실습) · **메모**(선택) · **사진 1장**(선택) 을 적고 **[기록 저장]**.
2. 성공하면 "기록됨 · 홈 KPI 에 반영". 작성자를 고르지 않았으면 "작성자를 먼저 선택하세요", 제목이 비었으면 "제목은 필수입니다".
3. 표가 아직 없으면 노란 안내 "표 준비 중(SQL 실행 대기) — 지금은 저장할 수 없습니다"가 뜨고 저장 단추가 막힙니다.
4. 한 번 저장한 기록은 앱에서 고치거나 지울 수 없습니다(남기기만 가능). 잘못 올렸으면 운영 담당에게.

### 홈 KPI 에는 이렇게 반영됩니다
- **IT 퀴즈**: 인당 **주 2회** 목표 · **IT 실습**: 인당 **주 1회** 목표(둘 다 홈 [주요 목표]). 팀장 제외, 작성자·날짜(KST)로 셉니다.
- 기록이 홈에 보이기까지 최대 60초(IT 기록은 가벼운 원본). 표가 없을 때 홈에는 0 이 아니라 "준비 중 · SQL 실행 대기"로 보입니다(02장).
- 목표 숫자는 관리 탭 KPI_TARGETS 의 `K21`(IT 실습)·`K34`(IT 퀴즈)로 바꿉니다(14장).
