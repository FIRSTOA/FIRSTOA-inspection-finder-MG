# 02. 홈 — CS KPI 현황판

## 무엇을 하는 화면인가
왼쪽 메뉴 맨 위 **홈**. CS팀이 **이번 주·이번 달·분기 목표 대비 어디까지 왔는지**를 숫자와 %로 한 판에 보여 주는 화면입니다(2026-10-23 첫 개편, **2026-10-24 전면 개편** — KPI 달성표가 주인공).
**홈에서는 아무것도 저장·전송하지 않습니다.** 위젯을 누르면 같은 숫자를 볼 수 있는 화면으로 이동할 뿐입니다(피드백 보드에 글 쓰는 것과 위젯 배치 바꾸기만 예외 — 배치는 이 기기에만 저장).
앱을 열면 첫 화면은 홈이 아니라 **FIELD**입니다.

위에서 아래로 이렇게 놓여 있습니다.
1. **한 줄 머리**: `10월 24일(토) · 44주차 · 4분기 · 갱신 방금` + 오른쪽 **[편집]**. 예전의 큰 시계·인사말·알약은 없어졌습니다(홈이 매초 다시 그려져 앱이 느려지던 원인이었음).
2. **CS KPI 현황판** — 기본 배치 순서
   1. **금일 현황** 띠 — 맨 왼쪽 "오늘" 날짜 + 오늘 점검(대)·AS·물류·방문 업체·오버홀·PC확장성·복합기확장성·초과사용 제안·재계약·미수 방문·불만·담당자 변경·교체양식·블로그 답글·받은 칭찬·고객 칭찬. 칩을 누르면 그 화면으로
   2. **KPI 달성표**(주인공, 전체 폭 두 줄) — 카드 머리 "KPI 달성표 · 이번 주"
      - **기간 칩 [주] [월] [분기]**(오늘은 금일 현황 띠가 맡습니다) + **[주요 목표 n] [전체 지표 n]**
      - 행: 지표명(단위·목표 근거 작은 글자) · **상태 알약** · **CS 전체**(큰 숫자 `실적/목표` + 막대, 점선 = 기간 경과 페이스) · **A·B·C·D·CSS 칸**(숫자 + 얇은 막대, 색 = 상태)
      - **행을 누르면 펼쳐집니다**: ⓐ 팀별 가로 막대(실적/목표/%) ⓑ **개인 칩**(이름 실적/목표, 달성 초록·부족 빨강, 팀별 묶음, 실적 많은 순) ⓒ 숫자 기준 한 줄 + [화면 열기 →]. 예전 "PC·복합기 확장성"·"초과사용 제안 방문" 위젯이 하던 팀·개인 보기는 여기서 합니다.
      - **폰**: 표 대신 **지표 카드 목록**(지표명·상태·CS 숫자·막대). 카드를 누르면 같은 내용이 펼쳐집니다.
      - **[주요 목표]**(처음 보기): 분기 점검 · PC확장성 인당 영업일 1 · 초과사용 제안 파트 월 2 · 블로그 답글 인당 주 2 · 오버홀 인당 주 2 · IT 실습 주 1 · IT 퀴즈 주 2
      - **[전체 지표]**: FIELD 실적 전부(현장 / 영업 / 접수 / 소통·성장 묶음). 목표가 없는 지표(칭찬·불만·물류 등)는 **실적만 크게** 보이고 지난 기간 대비 화살표가 붙습니다
   3. **분기 점검 진행** — **팀별만**(전체 큰 숫자는 없앰). 팀 5줄(A·B·C·D·CSS): `완료/대상 · %` + 막대(점선 = 분기 경과) + **필요 n/일·인 → 지금 n/일·인**(그 팀 인원 기준). 머리 칩 **[말일] [말일 10일 전]** 으로 기준을 바꿉니다(처음은 말일). 아래에 숫자 기준 한 줄과 [워킨맵 →]
   4. **미처리 전체 n건** — 큰 숫자 = **접수 + 물류 + 재계약 확인 지남**. 아래 줄 `접수 27 · 물류 44 · 재계약 확인 지남 0`, 그 아래 접수 종류별 작은 칸(복합기 AS·원격·IT·경영·운영·영업), 가장 오래된 건 한 줄. 오른쪽 ⓘ 를 누르면 세 가지의 뜻이 펼쳐집니다
   5. **미처리 일정** — 팀 탭 [전체]·[A]~[E]·[경영][운영][영업], 탭 안에서 접수·AS / 물류 두 묶음(예전과 같은 칸)
   6. **OKR 달성률** — **주 단위**. 칩 [이번 주] [이번 달], 아래 작은 **주별 막대**(이번 달 1~n주차 달성률, 지금 주 표시)
3. **운영·시스템**(처음엔 펼쳐져 있음, 머리를 누르면 접힘): 머리의 점 색으로 DB·시트 상태(초록 정상 / 노랑 지연 / 빨강 실패). 안에는 데이터베이스·시트 동기화·최근 배포·FIELD AI 에이전트 팀 알약, 비용(AI·문자), **오늘 전송 흐름(실시간 전송 현황판)**, AI 에이전트 팀 카드, 업데이트(최근 배포 목록), 맨 아래 **절약 추정**. 접어 두면 그 기기에서는 다음에도 접힌 채로 열리고, 접힌 동안은 전송 현황판(15초)·누적 건수 조회가 멈춥니다. (예전 "데이터 자산" 칸은 없어졌습니다.)
4. **피드백 보드**: 불편·버그·개선·기타를 적는 곳 → 맨 아래 시스템 줄

**없어진 위젯**(2026-10-24): 점검(이번 주)·AS(이번 주)·PC·복합기 확장성·초과사용 제안 방문·재계약 확인 지남(미처리 전체 카드 한 줄로 흡수)·미처리 요약. 숫자는 달성표 행(펼치기)에서 그대로 볼 수 있습니다.

## 순서대로 쓰는 법
1. 하루 시작에 홈을 열어 **금일 현황** 띠와 **미처리 전체 / 미처리 일정** 칸을 봅니다. 미처리 일정에서 팀 탭을 고르고, 줄을 누르면 접수 줄 → 서비스접수 미처리 현황(**[접수 미처리 현황 →]**), AS 일정 줄 → 일정리스트 미처리(**[AS 일정리스트 →]**)로 갑니다(물류 줄은 네이버 캘린더에서 완료).
2. **KPI 달성표**에서 기간 칩([주]·[월]·[분기])을 고릅니다. 그 기간을 쓸 수 없는 지표는 행에 실제 기간이 따로 적힙니다(예: OKR = 이번 주/이번 달, 미처리 = 열린 건, 초과사용 제안 = 이번 달 또는 분기).
3. **상태 알약**을 봅니다(실적/목표가 기간 경과 비율을 따라가는지 비교).

   | 알약 | 뜻 |
   |---|---|
   | **달성**(초록) | 목표 이상. 작을수록 좋은 지표(불만 등)는 목표 이하. 비율 지표는 목표 % 이상 |
   | **순항**(파랑) | 아직 목표 전이지만 `실적/목표` % 가 **기간 경과 %** 이상 — 이 속도면 목표에 닿음 |
   | **부족**(빨강) | `실적/목표` % 가 기간 경과 % 보다 낮음 |
   | **목표 없음**(회색) | 목표를 정하지 않은 지표(칭찬·물류 등). 실적만 보임 |
   | **준비 중**(점선 회색) | 원본 표가 아직 없음(SQL 실행 대기). 숫자 0 이 아닙니다 |

4. 궁금한 행을 눌러 **펼칩니다** — 팀 막대·개인 칩을 보고, [화면 열기 →] 로 같은 숫자를 보는 화면으로 갑니다. 개인 숫자는 펼쳤을 때만 보입니다.
5. **숫자 기준**: 위젯 머리의 (i)를 누르면(PC는 올려 두면) "숫자 기준: …" 이 펼쳐집니다. 위젯 맨 아래 한 줄도 같은 글입니다.
6. **위젯 배치 바꾸기**: [편집] →
   - PC: 손잡이(⋮⋮)를 끌어 옮기기(키보드 화살표도 됨) · 폰: [위]/[아래]
   - 크기 단추(1x1·2x1·2x2·4x1·**4x2**, 위젯마다 되는 크기만 — 달성표는 4x2 가 기본) · 눈 단추 = 숨기기
   - [위젯 추가] = 숨긴 위젯 다시 켜기(맨 끝에 붙음) · [기본 배치로] = 처음 모양 · [완료]
   - 배치는 **이 기기·이 브라우저에만** 저장됩니다(다른 기기는 기본 배치). 숨긴 위젯의 숫자는 읽지 않아 홈이 가벼워집니다. 위젯은 6개(금일 현황·KPI 달성표·분기 점검 진행·미처리 전체·미처리 일정·OKR)뿐이라, 예전에 저장한 배치에 있던 없어진 위젯은 저절로 빠집니다.
7. 카톡이 안 올라간 것 같으면 **운영·시스템**의 **오늘 전송 흐름**에서 그 방 칸 색을 봅니다(접어 두었으면 머리를 눌러 펼침). 머리에 **📱 봇 n · 💻 노트북 n**(오늘 배달한 **방 수**)이 크게 보이고, 방 목록 줄 끝의 📱/💻 는 그 방의 마지막 글을 누가 배달했는지입니다.
8. 앱이 불편하거나 고장 났으면 **피드백 보드**에 적고 [등록]. 상태는 접수 → 개발자 확인 → 개발 대기 → 개발 중 → 미리보기 확인 → 배포 요청 → 반영 완료(또는 반려).

## 자주 하는 실수·주의
- **갱신 주기**: 홈을 처음 열면 **가벼운 원본(미처리·접수·칭찬·OKR·IT 퀴즈/실습 등)이 먼저 뜨고, 점검·AS·확장성·활동 기록·워킨맵처럼 큰 원본은 몇 초 뒤에 채워집니다**. 그 사이 해당 칸은 "불러오는 중"입니다. 보는 동안 저절로 갱신됩니다 — 가벼운 원본(달성표 안의 미처리·접수·칭찬·초과조정·불만·사무실 일지·IT 퀴즈/실습)은 **60초**, 무거운 원본(점검·AS·확장성·활동 기록·워킨맵·OKR 보고서·블로그 등)은 **5분**(그래서 금일 현황 점검 숫자가 최대 5분 늦을 수 있음). 머리의 "갱신 n분 전"이 마지막으로 읽은 시각입니다. **다른 화면·다른 탭에 가 있는 동안 홈은 완전히 쉽니다**(계산·조회 모두) — 그래서 다른 화면이 끊기지 않습니다. 돌아오면 다시 읽습니다. 위젯의 [다시 불러오기]는 즉시 전부 다시 읽습니다.
- **"—" · "0" · "준비 중" · "원본 연결 필요"는 모두 다릅니다.**
  - "—" + "불러오지 못했습니다" = 읽기 실패(마지막 값과 몇 분 전 값인지 같이 보임). 0 이 아닙니다.
  - "0 · 기록 없음" = 정말 기록이 없는 것.
  - 점선 회색 **"준비 중 · SQL 실행 대기"** = 원본 표가 아직 없는 것(미수 방문, IT 퀴즈·실습 표 등). 숫자는 보이지 않습니다.
  - 회색 **"원본 연결 필요"**(금일 현황 띠) = FIELD 에 그 숫자를 적는 곳이 아직 없는 것.
- 노란 줄 "목표 설정: … 무시한 값"은 관리 탭 KPI_TARGETS 에 틀린 칸이 있다는 뜻입니다(그 칸만 기본값으로 셈, 14장).
- 팀장 기록은 모든 KPI에서 빠집니다. **오버홀은 파트장·부파트장도 빠집니다**(아래 "숫자가 어떻게 세어지나").
- OKR 칸에 **"이번 주 OKR 미작성 n팀"** 이 보이면 그 파트가 이번 주 판정을 아직 하나도 적지 않은 것입니다(0% 가 아님). 11장에서 적습니다.
- 물류 일정은 홈에서 완료할 수 없습니다. 네이버 캘린더 또는 일정리스트에서 처리하세요.
- **시트 동기화 "실패 n · n일 전"**(운영·시스템 시트 동기화 알약·접힌 머리): 최근 7일 안 시트 기입 작업 중 재시도 5회를 끝내고도 실패한 건수와, 가장 최근 실패가 며칠 전인지("오늘"이면 오늘)입니다. 7일이 지나면 저절로 0 이 됩니다. 어느 접수인지·다시 실행은 **관리 탭 → 시트 기입 최근 작업**에서 봅니다(14장). 예: "행 없음"은 시트에서 그 행이 지워졌을 때 나옵니다.
- "절약 추정"은 실제 측정값이 아니라 **기록 1건당 약 10분**으로 계산한 어림값입니다.

## 숫자가 어떻게 세어지나
홈 위젯은 계산을 새로 하지 않고, 조회 탭·주간현황판(팀 현황·순위표)·워킨맵·OKR·접수 현황판이 쓰는 **같은 함수**를 부릅니다. 그래서 위젯을 눌러 간 화면의 같은 기간 숫자와 같아야 합니다(다르면 버그 — 피드백 보드에 적어 주세요).

| 지표 | 세는 법 |
|---|---|
| 점검(대) · AS(건) | 점검·AS 표. 점검 = 기기 대수 · AS = 양식 건수 · 같은 날 같은 업체 같은 기기 재전송은 1 · 오발송 삭제·팀장 제외 · 팀 = 지역 칸(없으면 작성자 팀). 팀 현황·순위표·조회 탭과 같은 숫자 |
| 분기 점검 진행(팀별) | 워킨맵 기준. 분기점검은 G5·G12면 완료, 매월점검은 G2=1·G3=2·G5/G12=3단위(3이 만점). 필요 = 그 팀의 남은 단위 ÷ 남은 영업일 ÷ **그 팀 인원**, 지금 = 완료 단위 ÷ 분기 시작~오늘 영업일 ÷ 그 팀 인원(영업일 = 주말·공휴일·설정 휴일 제외). 계산은 끝까지 하고 화면에만 소수 1자리로 보입니다. 남은 영업일이 0 이거나 인원을 못 읽으면 "—" |
| PC·복합기 확장성 | 확장성 표(시트 포함) · 같은 날 같은 업체 1건 · 팀장 제외. PC 목표 = 인원 × 영업일 × 1 |
| 초과사용 제안 방문 | 초과조정 양식 1건 = 방문 1건(같은 사람·날·업체는 1) · 목표 = 파트 월 2건(전체 월 8건·분기 24건) |
| 블로그 답글 | 블로그 기록 시트 한 행 = 1건. 목표 = 인원 × 주 2(기간 영업일 ÷ 5 주로 환산) |
| **오버홀** | 사무실 일지 기계오버홀 점수 합. 목표 = 인원 × 주 2. **집계와 목표 인원 모두에서 팀장·파트장·부파트장을 뺍니다**(관리 탭 인원의 호칭 기준, 14장). 다른 지표는 팀장만 뺍니다 |
