# 02. 홈 — 실시간 운영 현황판

## 무엇을 하는 화면인가
왼쪽 메뉴 맨 위 **홈**. 회사 CS 업무가 지금 어떻게 돌아가는지 한 판에 보여 주는 화면입니다.
**홈에서는 아무것도 저장·전송하지 않습니다.** 카드를 누르면 해당 화면으로 이동할 뿐입니다(피드백 보드에 글 쓰는 것만 예외).
앱을 열면 첫 화면은 홈이 아니라 **FIELD**입니다.

위에서 아래로 이렇게 놓여 있습니다.
1. **관제 덱**: 큰 시계·날짜, "N분기 운영 중 · N주차 · CS 재직 N명 · 갱신 n분 전", 인사말("○○ 프로, … 이번 주 내 기록 N건 · 팀 전체 N건")
   - 인사말의 이번 주 숫자는 "이번 주 내 점검 n대 · AS n건" 꼴입니다.
   - 상태 알약: **데이터베이스**(응답 속도) · **시트 동기화**(정상/대기/실패) · **최근 배포** · **FIELD AI 에이전트 팀**(누르면 아래 에이전트 팀 카드로 이동) · **비용**(AI 질문·문자 금액, 누르면 내역) · **미처리 접수**(누르면 서비스접수의 미처리 현황)
2. **실시간 전송 현황판**: 카톡방마다 색 칸(지연 · 전송 중 · 정상 · 조용), 오늘 누가 어떤 양식을 어느 방으로 보냈는지 흐름, 업무폰 카톡 봇·노트북 실행기 상태, 밀린 글 수.
3. **지표**: 미처리 일정 · 오늘 점검(대) · 이번 주 방문 · 키맨·주소 변경 7일 · 데이터 자산 · 최근 7일 기록 추이 · 이번 주 지역별 기록 · N분기 점검 진행률(워킨맵 기준)
4. **피드백 보드**: 불편·버그·개선·기타를 적는 곳
5. **절약 추정**(Impact), **FIELD AI 에이전트 팀** 카드, **업데이트**(최근 배포 목록), 맨 아래 시스템 줄

## 순서대로 쓰는 법
1. 하루 시작에 홈을 열어 **미처리 일정** 칸을 봅니다. 탭은 [전체] · [A]~[E] · [경영][운영][영업](지원 3종이 켜졌을 때).
2. 목록 안은 **접수·AS** 묶음과 **물류** 묶음으로 나뉩니다. 줄을 누르면:
   - 접수 줄 → 서비스접수의 미처리 현황 (**[접수 미처리 현황 →]**)
   - AS 일정 줄 → 일정리스트 미처리 (**[AS 일정리스트 →]**)
   - 물류 줄 → 네이버 캘린더에서 완료하라는 안내
3. 카톡이 안 올라간 것 같으면 **실시간 전송 현황판**에서 그 방 칸 색을 봅니다. 빨강(지연)이면 담당자에게 알리세요.
4. 앱이 불편하거나 고장 났으면 **피드백 보드**에 분류(불편·버그·개선·기타)와 화면을 골라 적고 [등록]. 같은 불편이면 **[나도 그래요]**. 상태는 접수 → 개발자 확인 → 개발 대기 → 개발 중 → 미리보기 확인 → 배포 요청 → 반영 완료(또는 반려) 순으로 바뀝니다.
5. 새 기능·수정 내용은 **업데이트** 카드에서 날짜별로 봅니다. **[최근 배포 더 보기]** 로 더 펼칩니다. 이 목록은 배포할 때 자동으로 만들어집니다.

## 자주 하는 실수·주의
- 홈 숫자는 **보는 동안 저절로 갱신**됩니다(전송 현황 15초, 나머지 지표 60초, 미처리 접수 카드 5분). 다른 탭에 가 있는 동안은 쉬고, 돌아오면 다시 읽습니다.
- 맨 아래 노란 줄 "일부 지표를 못 불러왔습니다"는 그 지표만 실패한 것입니다. 다른 숫자는 정상입니다.
- 물류 일정은 홈에서 완료할 수 없습니다. 네이버 캘린더 또는 일정리스트에서 처리하세요.
- 원격 접수 중 **7일이 넘은 원격대기**는 미처리에서 뺍니다(원격팀이 FIELD 밖에서 처리하므로).
- "절약 추정"은 실제 측정값이 아니라 **기록 1건당 약 10분**으로 계산한 어림값입니다.

## 숫자가 어떻게 세어지나
| 칸 | 세는 법 |
|---|---|
| 오늘 점검(대) | 오늘 점검 **기기 대수**, 아래 줄에 AS 건수·이번 주 점검(대)·AS(건). 셈법: 점검 = 기기 대수 · AS = 양식 건수 · 같은 날 같은 업체 같은 기기 재전송은 1 · 오발송 삭제·팀장 기록 제외 · 팀 = 지역 칸(없으면 작성자 팀). 팀 현황·순위표·조회 탭과 **같은 숫자** |
| 이번 주 내 점검·AS | 위와 같은 셈법으로 작성자가 나인 것만 |
| 이번 주 지역별 기록 | 위와 같은 셈법, 팀 = 지역 칸(없으면 작성자 팀) |
| 이번 주 방문 | 방문 기록(FIELD 전송 때 생김) 중 방문한 건수, 시간은 양식 소요시간 합 |
| 키맨·주소 변경 7일 | 최근 7일 담당자/주소 변경 건수, "인사 대기"는 담당·키맨·명의 변경 중 인사 체크 안 된 것 |
| 절약 추정 | 이번 주 양식 **장수** × 약 10분(이것만 장수 기준) |
| 데이터 자산 | 지금까지 쌓인 점검+AS 기록 수, 사진 장수 |
| N분기 점검 진행률 | 워킨맵 기준. 분기점검은 G5·G12면 완료, 매월점검은 G2=1·G3=2·G5/G12=3회로 환산(3회가 만점) |
| 미처리 일정 | 열린 접수 6종 + 지난 날짜 미완료 물류 일정 + 접수와 연결 안 된 미완료 AS 일정. 같은 건이 접수와 AS 일정에 다 있으면 접수 쪽으로 한 번만. 팀 탭 합 = 전체 |
| 미처리 접수(알약) | 서비스접수 미처리 현황판과 **같은 계산**. 관리 탭 "미처리 = 시트 상태 기준" 스위치를 켜면 영업·경영·원격·IT는 접수 시트 상태로 셈(06장) |

- 2026-10-22부터 홈·조회·팀 현황·순위표의 점검·AS는 **같은 표·같은 셈법**입니다(카드 아래 "기준:" 한 줄로도 보임).
