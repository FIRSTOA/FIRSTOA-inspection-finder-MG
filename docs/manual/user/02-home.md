# 02. 홈 — CS KPI 현황판

## 무엇을 하는 화면인가
왼쪽 메뉴 맨 위 **홈**. CS팀이 **오늘·이번 주·이번 달·분기 목표 대비 어디까지 왔는지**를 숫자와 %로 한 판에 보여 주는 화면입니다(2026-10-23 개편, 이전 이름 "실시간 운영 현황판").
**홈에서는 아무것도 저장·전송하지 않습니다.** 위젯을 누르면 같은 숫자를 볼 수 있는 화면으로 이동할 뿐입니다(피드백 보드에 글 쓰는 것과 위젯 배치 바꾸기만 예외 — 배치는 이 기기에만 저장).
앱을 열면 첫 화면은 홈이 아니라 **FIELD**입니다.

위에서 아래로 이렇게 놓여 있습니다.
1. **관제 덱**: 큰 시계·날짜, "N분기 운영 중 · N주차 · CS 재직 N명 · KPI 갱신 n분 전", 인사말("○○ 프로, … 이번 주 내 점검 n대 · AS n건 · 전체 점검 n대 · AS n건")
2. **CS KPI 현황판**: 기간 칩 **[오늘] [이번 주] [이번 달] [분기]** 과 **[편집]**, 그 아래 위젯들(기본 배치)
   1. **금일 현황** 띠 — 오늘 점검(대)·AS·물류·방문 업체·오버홀·PC확장성·복합기확장성·초과사용 제안·재계약·미수 방문·불만·담당자 변경·교체양식·블로그 답글·받은 칭찬·고객 칭찬. 칩을 누르면 그 화면으로
   2. **분기 점검 진행** — 워킨맵과 같은 꼴 "점검 373/1469 · 25%" + 막대(점선 = 분기 경과) + "분기 말일 · 영업일 n일 → 필요 x.x · 지금 y.y(단위/일·인)", "말일 10일 전" 줄, 팀별 %
   3. **KPI 달성표** — 행 = KPI, 열 = **CS 전체 · A~D팀 · E(CSS)팀**, 행 이름(▶)을 누르면 **개인**별. 칸은 "실적/목표"와 막대
      - **[주요 목표]**(처음 보기): 분기 점검 · PC확장성 인당 영업일 1 · 초과사용 제안 파트 월 2 · 블로그 답글 인당 주 2 · 오버홀 인당 주 2 · IT 실습 주 1 · IT 퀴즈 주 2
      - **[전체 지표]**: FIELD 실적 전부(현장 / 영업 / 접수 / 소통·성장 묶음). 목표가 없는 지표(칭찬·불만·물류 등)는 **"n/—" 건수만**
   4. **점검**(대, 지난 기간 대비 화살표·팀별) · **PC·복합기 확장성**(팀별 막대, 점선 = 목표) · **초과사용 제안 방문**(파트 월 2건 목표 대비, 남은 영업일) · **미처리 일정**(예전 홈과 같은 칸 — 탭 [전체]·[A]~[E]·[경영][운영][영업], 탭 안에서 접수·AS / 물류 두 묶음, 팀 탭 합 = 전체) · **미처리 접수**(예전 관제 덱 카드, 누르면 서비스접수 미처리 현황) · **AS**(최근 8주 추세) · **OKR 달성률(이번 달)** · **재계약 확인 지남**
   5. 숨겨 둔 위젯: **미처리 요약(접수 + 지난 일정)** — 오래된 순 목록과 접수/일정/물류/7일 넘음 칩. [편집] → [위젯 추가]로 켭니다
3. **운영·시스템**(처음엔 펼쳐져 있음, 머리를 누르면 접힘): 머리의 점 색으로 DB·시트 상태(초록 정상 / 노랑 지연 / 빨강 실패)를 봅니다. 안에는 데이터베이스·시트 동기화·최근 배포·FIELD AI 에이전트 팀 알약, 비용(AI·문자), **실시간 전송 현황판**, 데이터 자산·절약 추정, AI 에이전트 팀 카드, 업데이트(최근 배포 목록). 접어 두면 그 기기에서는 다음에도 접힌 채로 열리고, 접힌 동안은 전송 현황판(15초)·누적 건수 조회가 멈춥니다.
4. **피드백 보드**: 불편·버그·개선·기타를 적는 곳 → 맨 아래 시스템 줄

## 순서대로 쓰는 법
1. 하루 시작에 홈을 열어 **금일 현황** 띠와 **미처리 일정** 칸을 봅니다. 팀 탭을 고르고, 줄을 누르면 접수 줄 → 서비스접수 미처리 현황(**[접수 미처리 현황 →]**), AS 일정 줄 → 일정리스트 미처리(**[AS 일정리스트 →]**)로 갑니다(물류 줄은 네이버 캘린더에서 완료).
2. 기간 칩을 바꾸면(예: [이번 달]) 달성표·점검·AS·확장성 숫자가 그 기간으로 바뀝니다. 그 기간을 쓸 수 없는 지표는 행·위젯 머리에 실제 기간이 따로 적힙니다(예: OKR = 이번 달, 미처리·재계약 확인 지남 = 열린 건, 초과사용 제안 = 이번 달 또는 분기).
3. **KPI 달성표**에서 [주요 목표] ↔ [전체 지표]를 고릅니다. 폰에서는 KPI 카드를 누르면 팀별, 다시 [개인 n명 보기]로 개인별이 펼쳐집니다. 행 끝 화살표(→, 폰은 [자세히])는 같은 숫자를 보는 화면으로 이동합니다.
4. **숫자 기준**: 위젯 머리의 (i)를 누르면(PC는 올려 두면) "숫자 기준: …" 이 펼쳐집니다. 위젯 맨 아래 한 줄도 같은 글입니다.
5. **위젯 배치 바꾸기**: [편집] →
   - PC: 손잡이(⋮⋮)를 끌어 옮기기(키보드 화살표도 됨) · 폰: [위]/[아래]
   - 크기 단추(1x1 → 2x1 → 2x2 …, 위젯마다 되는 크기만) · 눈 단추 = 숨기기
   - [위젯 추가] = 숨긴 위젯 다시 켜기(맨 끝에 붙음) · [기본 배치로] = 처음 모양 · [완료]
   - 배치는 **이 기기·이 브라우저에만** 저장됩니다(다른 기기는 기본 배치). 숨긴 위젯의 숫자는 읽지 않아 홈이 가벼워집니다.
6. 카톡이 안 올라간 것 같으면 **운영·시스템**의 실시간 전송 현황판에서 그 방 칸 색을 봅니다(접어 두었으면 머리를 눌러 펼침).
7. 앱이 불편하거나 고장 났으면 **피드백 보드**에 적고 [등록]. 상태는 접수 → 개발자 확인 → 개발 대기 → 개발 중 → 미리보기 확인 → 배포 요청 → 반영 완료(또는 반려).

## 자주 하는 실수·주의
- 홈을 처음 열면 **가벼운 칸(미처리·접수·칭찬·OKR 등)이 먼저 뜨고, 점검·AS·확장성·워킨맵처럼 큰 원본은 몇 초 뒤에 채워집니다**(2026-10-24 속도 개선). 그 사이 해당 칸은 "불러오는 중"입니다. 다른 화면·다른 탭에 가 있는 동안 홈은 완전히 쉽니다(시계·계산·조회 모두) — 그래서 다른 화면이 끊기지 않습니다.
- 홈 숫자는 **보는 동안 저절로 갱신**됩니다(미처리 일정 칸 60초, 미처리 접수 카드 5분은 예전과 같음): 달성표·띠의 미처리·접수·칭찬·초과조정·불만·사무실 일지는 60초, 점검·AS·확장성·활동 기록·워킨맵·OKR·블로그 등 큰 원본은 **5분**(그래서 금일 현황 점검 숫자가 최대 5분 늦을 수 있음). 다른 화면·다른 탭에 가 있는 동안은 쉬고, 돌아오면 다시 읽습니다. 위젯의 [다시 불러오기]는 즉시 전부 다시 읽습니다.
- **"—" 와 "0" 은 다릅니다.** "—" + "불러오지 못했습니다"는 읽기 실패(마지막 값과 몇 분 전 값인지 같이 보임), "0 · 기록 없음"은 정말 기록이 없는 것, "준비 중"은 원본 표가 아직 없는 것(미수 방문 등 SQL 실행 대기), 회색 "원본 연결 필요"는 FIELD에 그 숫자를 적는 곳이 아직 없는 것(IT 실습·IT 퀴즈).
- 노란 줄 "목표 설정: … 무시한 값"은 관리 탭 KPI_TARGETS 에 틀린 칸이 있다는 뜻입니다(그 칸만 기본값으로 셈, 14장).
- 개인 숫자는 달성표에서 행을 펼칠 때만 보입니다. 팀장 기록은 모든 KPI에서 빠집니다.
- 물류 일정은 홈에서 완료할 수 없습니다. 네이버 캘린더 또는 일정리스트에서 처리하세요.
- "절약 추정"은 실제 측정값이 아니라 **기록 1건당 약 10분**으로 계산한 어림값입니다.

## 숫자가 어떻게 세어지나
홈 위젯은 계산을 새로 하지 않고, 조회 탭·주간현황판(팀 현황·순위표)·워킨맵·OKR·접수 현황판이 쓰는 **같은 함수**를 부릅니다. 그래서 위젯을 눌러 간 화면의 같은 기간 숫자와 같아야 합니다(다르면 버그 — 피드백 보드에 적어 주세요).

| 지표 | 세는 법 |
|---|---|
| 점검(대) · AS(건) | 점검·AS 표. 점검 = 기기 대수 · AS = 양식 건수 · 같은 날 같은 업체 같은 기기 재전송은 1 · 오발송 삭제·팀장 제외 · 팀 = 지역 칸(없으면 작성자 팀). 팀 현황·순위표·조회 탭과 같은 숫자 |
| 이번 주 내 점검·AS(인사말) | 위와 같은 셈법, 작성자가 나인 것만(이번 주 = 월~일) |
| 분기 점검 진행 | 워킨맵 기준. 분기점검은 G5·G12면 완료, 매월점검은 G2=1·G3=2·G5/G12=3단위(3이 만점). 필요 = 남은 단위 ÷ 남은 영업일 ÷ 인원, 지금 = 완료 단위 ÷ 분기 시작~오늘 영업일 ÷ 인원(영업일 = 주말·공휴일·설정 휴일 제외). 계산은 끝까지 하고 화면에만 소수 1자리로 보입니다 — 남은 양이 아주 적어도 "목표 달성"으로 잘못 나오지 않습니다(남은 게 0일 때만 "목표 달성"). 명단을 못 읽으면 4인 기준 |
| PC·복합기 확장성 | 확장성 표(시트 포함) · 같은 날 같은 업체 1건 · 팀장 제외. PC 목표 = 인원 × 영업일 × 1 |
| 초과사용 제안 방문 | 초과조정 양식 1건 = 방문 1건(같은 사람·날·업체는 1) · 목표 = 파트 월 2건(전체 월 8건·분기 24건) |
| 블로그 답글 · 오버홀 | 블로그 기록 시트 한 행 = 1건 · 사무실 일지 기계오버홀 점수 합. 목표 = 인원 × 주 2(기간 영업일 ÷ 5 주로 환산) |
| 물류·재계약·불만·담당자 변경·교체양식 | 활동 기록(팀 현황 칸과 같음). 재계약·불만은 같은 업체 1곳 |
| 미처리 일정(칸) · 미처리 요약(위젯) | 열린 접수 6종(90일) + 지난 날짜 미완료 물류·AS 일정(180일, 매월점검 제외). 같은 건이 접수와 AS 일정에 다 있으면 접수 쪽으로 한 번만. 시트 기준 스위치를 켜면 영업·경영·원격·IT는 접수 시트 상태로(06장). 팀 탭 합 = 전체 |
| 미처리 접수(카드) | 서비스접수 미처리 현황판과 **같은 계산** |
| 재계약 확인 지남 | 업체별 마지막 재계약 기록이 끝나지 않았고 다음확인일 < 오늘. 다음확인일을 글자로 적은 옛 기록은 따로 셈 |
| OKR 달성률 | 이번 달 파트 종합 판정 중 완료·해당없음 / 판정 있는 목표(A~D) |
| 받은·보낸 칭찬 · 고객 칭찬 | 칭찬 게시판(받는 사람·쓴 사람) · FIELD 칭찬 양식(작성 직원) |
| 절약 추정 | 이번 주 양식 **장수** × 약 10분(이것만 장수 기준) |
| 데이터 자산 | 지금까지 쌓인 점검+AS 기록 수, 사진 장수(운영·시스템을 펼쳤을 때만 읽음) |

- 목표 숫자와 [주요 목표]에 넣을 지표는 관리 탭 **KPI_TARGETS** 로 바꿉니다(14장). 비워 두면 4분기 OKR·팀장 지시 기본값.
