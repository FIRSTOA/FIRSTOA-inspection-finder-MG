# 12. 워킨맵

## 무엇을 하는 화면인가
왼쪽 메뉴 "현장·동선" 묶음의 **워킨맵**. 이번 분기에 어디를 **점검·재계약 방문**해야 하는지 팀별로 **지도와 목록**으로 보는 화면입니다.
- 색(G1~G12) = 진행 상태. 목록 배지 = 미수·초과·불만·재계약처럼 "가기 전에 알아야 할 것".
- FIELD에서 점검 양식을 점검방으로 보내면 **색이 자동으로 완료색으로 바뀝니다**.
- 여기서 고친 것은 공용으로 저장되어 팀 전체가 같은 지도를 봅니다("공용 저장됨"). 네이버·카톡으로는 아무것도 보내지 않습니다.

## 순서대로 쓰는 법
1. 지도 오른쪽 위 **[조건]**: 담당 팀 · 분기(1Q~4Q) · 업무(전체 / 분기점검 / 매월점검 / 재계약). 고른 값은 다음에도 기억됩니다. (E팀 선택 가능 여부 **(확인 필요)**)
2. **[색상 N]** 에서 보고 싶은 색만 체크합니다(체크 안 하면 전체).
3. 목록에서 거래처를 한 번 누르면 지도가 그곳으로, 다시 누르면 펼쳐집니다. 폰은 지도 | 목록 탭, 핀을 누르면 아래 업체 카드.
4. 펼친 줄에서 **최근 점검 비교**(분기점검만)와 여분 판단을 보고, 필요하면 **[자가신청]** → FIELD 점검 탭에 그 업체 양식이 열립니다(수량 확인 후 "자가"로 전송).
5. **F/FIELD 단추**는 양식을 바로 만들지 않고 FIELD의 업체 검색 창(최근 방문 양식 목록)을 엽니다. 거기서 [불러오기].
6. 점검을 마치면 **FIELD에서 점검방으로 전송** — 색은 손으로 바꾸지 않아도 됩니다(03장).
7. **[진행률]**: 팀별 완료율·남은 영업일·하루 목표. **[주차분석]**: 순조 / 주의 / 스퍼트 필요.
8. 여러 곳 색을 한꺼번에 바꾸려면 **[목록 편집]**. 명단은 **[엑셀 불러오기]**, 지금 목록은 **[현재 목록 내보내기]**.

## 자주 하는 실수·주의
- **워킨맵은 손으로 색칠하지 마세요.** FIELD 전송으로 바꿔야 완료 날짜가 남고 주차분석에 잡힙니다.
- FIELD 토스트 "확인 필요 n대"·"일치 항목 없음"은 워킨맵에서 그 기기를 못 찾은 것입니다. 그 업체만 손으로 G5로 바꾸고, 다음부터 자동으로 맞게 항목 메모에 시리얼이나 자산기번을 적어 두세요.
- AS방으로만 보내면 워킨맵이 바뀌지 않습니다. 점검방 + 구분 "점검"이어야 합니다.
- "왜 거래처가 안 보이지?" → [조건] 버튼이 검게 켜져 있는지, [색상]에 숫자가 붙어 있는지 먼저 보세요. 검색어를 치면 색 체크는 무시하고 찾습니다.
- 목록이 다 불러와지기 전에는 저장이 막힙니다(빈 목록으로 덮어쓰는 사고 방지).
- 엑셀의 수식 좌표도 읽습니다. 좌표가 없는 곳은 주소로 좌표를 채웁니다(10/15 수정).

## 워킨맵(기존) 동기화 (2026-10-31 가동 — 가져오기만, 되밀기는 아직)
예전에 쓰던 워킨맵 앱(workinmap.com)에서 바꾼 **색(G 라벨)·지도에서 ON/OFF·메모**가 이 화면의 같은 거래처에 자동으로 들어옵니다. 하루 4번(09·12·15·18시), 지난 분기는 새벽 06:10 한 번. 관리자가 관리 탭 스위치를 켜기 전까지는 아무것도 바뀌지 않습니다.
- 목록에 따로 표시는 없습니다(배지는 헷갈려서 뺌). 하루 4번(09·12·15·18시) 워킨맵 색·메모를 따라옵니다.
- 동기화로 붙은 메모는 끝에 `(워킨맵 2026-10-20)` 처럼 워킨맵에 적힌 날짜가 붙습니다. 임대료·미수금·계약종료년월 같은 정형 줄은 덧붙지 않고 최신값으로 바뀝니다.
- 워킨맵 화면에는 동기화 관련 안내 줄이 없습니다(직원 혼동 방지). 확인 필요 건은 관리 탭 › 기타 설정 › 워킨맵 동기화 카드에서만 봅니다.
- 웹앱이 따로 쌓은 것은 지키는 쪽입니다: FIELD 전송으로 된 G5/G12 완료를 워킨맵이 낮추면 자동 반영하지 않고 확인 큐로 보냅니다. 메모는 덮지 않고 없는 줄만 붙입니다.
- **[엑셀 불러오기]의 "같은 목록 교체"는 동기화 중인 팀·분기·업무에서는 막힙니다.** "이 범위는 워킨맵 동기화 중이라 교체할 수 없습니다(추가만 가능)"가 뜨면 "기존 목록에 추가"를 쓰세요. 교체(통째로 지우고 넣기)를 하면 워킨맵과의 짝이 끊겨 다음 회차가 같은 곳을 새 장소로 또 넣기 때문입니다.
- 웹앱에서 바꾼 것을 워킨맵에 되써 넣는 것(되밀기)은 아직 꺼져 있습니다(P2).

## 숫자가 어떻게 세어지나
- 완료로 치는 라벨: 분기점검 = **G5·G12**, 재계약 = **G5만**. 매월점검 = G2 1회 · G3 2회 · G5(또는 G12) 3회로 환산.
- 재계약 G5·G7·G12는 CS 방문 대상에서 빠집니다(재계약 준비·자동 일정과 같은 규칙). **G6 은 2026-10-27 부터 진행중 = 방문 대상에 들어갑니다.** 홈 "재계약 진행" % = G5 ÷ (G7 을 뺀 전부).
- 홈의 "N분기 점검 진행률"도 같은 셈법입니다(02장).
- 주차분석: 분기 경과 % 대비 점검 완료 %가 같거나 높으면 순조, 10%p 안이면 주의, 그보다 낮으면 스퍼트 필요.
