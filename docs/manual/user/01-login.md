# 01. 로그인 (그룹웨어 계정)

## 무엇을 하는 화면인가
FIELD는 회사 **그룹웨어 계정**으로 들어갑니다. FIELD에는 따로 비밀번호가 없고, 비밀번호는 그룹웨어 화면에서만 입력합니다.
로그인하면 **작성자 이름이 자동으로 맞춰지고 고정**됩니다. 폰·PC 모두 같습니다.

## 순서대로 쓰는 법
1. FIELD 주소를 엽니다. 로그인한 적이 없거나 기한이 지났으면 화면에 "그룹웨어 로그인으로 이동 중…"이 잠깐 뜨고 **그룹웨어 로그인 화면**으로 넘어갑니다.
2. 그룹웨어 아이디·비밀번호를 넣습니다. (그룹웨어 공지: 2026-11-01부터 사번으로만 로그인 — 그룹웨어 쪽 규칙입니다.)
3. 자동으로 FIELD로 돌아오고, 처음 화면(FIELD)이 열립니다.
4. 내 계정 확인: 왼쪽 메뉴(폰은 ☰) 맨 아래 **내 이름**을 누르면 "그룹웨어 연결됨" 카드가 열리고 부서·사번·권한·로그인 시각이 보입니다.
5. 로그아웃: 같은 카드의 **[로그아웃]**.

## 자주 하는 실수·주의
- **로그인은 7일 유지됩니다.** 7일이 지나면 화면을 다시 볼 때 그룹웨어 로그인으로 넘어갑니다(켜 둔 채 7일 지난 폰도 화면을 다시 켜면 확인함).
- **계정을 바꾸려면** FIELD에서 로그아웃만 해서는 안 됩니다. 그룹웨어에 로그인이 살아 있으면 바로 같은 계정으로 다시 들어옵니다("그룹웨어 로그인이 살아 있으면 바로 다시 들어옵니다."). 그룹웨어에서도 로그아웃한 뒤 다시 로그인하세요.
- 로그인 후에는 양식의 작성자 칸이 **고르는 칸이 아니라 이름 글자**로 보입니다. 다른 사람 이름으로 쓸 수 없습니다. 남아 있던 다른 이름은 로그인한 이름으로 바뀝니다.
- 그룹웨어 로그인 화면은 다른 부서(경영지원팀) 것이라 FIELD에서 고칠 수 없습니다. 로그인 자체가 안 되면 그룹웨어 담당자에게 문의하세요. 브라우저의 비밀번호 저장 기능을 쓰면 편합니다.
- 로그인이 실패해 돌아오면 "그룹웨어 계정으로 로그인" 문 화면이 뜹니다. **[그룹웨어로 로그인 →]** 을 다시 누르세요.
- **로그인 없이 열리는 것**: 현장 사진 앨범 링크, 점검 리포트 링크, 앱 안 사용설명서(`/guide/…`), 2026 성과 리포트. 카톡으로 받은 사람이 바로 볼 수 있게 일부러 열어 둔 것입니다.
- 관리 탭 **그룹웨어 로그인 필수** 스위치가 꺼져 있으면 로그인 없이 열리고, 예전처럼 작성자를 직접 고릅니다(14장). 2026-10-08에 켰고, 2026-10-22 확인 때도 켜져 있습니다.

## 숫자가 어떻게 세어지나
해당 없음. 다만 로그인한 이름이 모든 기록의 **작성자**가 되고, 팀 현황·순위표의 사람별 숫자는 이 이름으로 묶입니다. 관리 탭 인원 명단의 이름과 그룹웨어 이름 표기가 다르면 팀이 잘못 잡힐 수 있습니다 **(확인 필요: 이름 표기 불일치 사례)**.
