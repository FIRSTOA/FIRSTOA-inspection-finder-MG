## 1. 한 줄 목표와 쓰는 사람
- 목표: 서비스접수 › [경영지원]·[전략영업]·[운영지원]·[IT] 저장 때 카톡방에 가는 글을 지금의 `[경영지원 접수] ■ 업체 …` 8~13줄에서 **각 방에서 사람이 붙여 오던 글과 글자 배열이 같은 글**로 바꾼다(경영·전략영업·IT = 표 카드, 운영 = 자유 글 틀). IT 는 지금 CS 접수와 같은 긴 양식(`IT A/S⇥…` + AS 이력·자가사용내역)이 나간다. 값은 시트 카드가 자동으로 채우던 **임대리스트의 같은 칸**에서 가져온다(사람이 적는 칸은 앱 폼 값).
- 쓰는 사람: 접수자 = 경영지원 파트·전략영업·운영·CS(IT 접수)(PC, 서비스접수 화면). 읽는 사람 = 각 부서 접수 카톡방(폰·PC). 고객은 안 씀.

## 3. 카드 양식 정의 — 공통 직렬화 + 양식별 칸 목록

### 3-1. 공통 직렬화 규칙 (한 함수)
카드 = 줄 목록. 줄 종류 4가지:
| 줄 종류 | 직렬화 | 쓰는 곳 |
|---|---|---|
| `cells` | 셀 값들을 `SEP_CELL`(탭)로 이음 — 시트 범위를 복사하면 나오는 글자 배열. 병합 셀은 첫 칸에 값, 나머지는 빈 칸(탭만) | 경영 1~15행, 영업 머리 줄 |
| `pairs` | `라벨{SEP_LV}값{SEP_PAIR}라벨{SEP_LV}값` | 영업 본문(`SEP_LV = ":   "`, `SEP_PAIR = "   /   "`). 경영은 `cells` 로 충분 |
| `blank` | 빈 줄 | 영업 머리 뒤 |
| `text` | 고정 접두 + 값(여러 줄 허용) | 영업 `🔹 접수내용:   …` |

- 각 줄 **끝의 빈 칸·공백은 지운다**(trimEnd). 줄 가운데 빈 칸은 남긴다(라벨 위치가 실물과 같아야 눈에 익는다).
- 값 안 줄바꿈: **접수내용만 그대로**. 나머지 칸(키맨·기본매수 등)은 ` / ` 로 이어 한 줄로. 시트 복사 때 생기던 `"…"` 따옴표·`_x000d_` 는 만들지 않는다.
- 탭 표시: 사용자 실물에서 칸 사이가 넓은 공백으로 보이는 것이 탭이 카톡에서 공백으로 보인 결과. QA가 폰·PC 둘 다 확인하고, 무너지면 `SEP_CELL` 상수 하나를 공백 3칸으로 바꾼다.
- 한 줄 두 쌍(실물 그대로)이 기본(Q1).
- 직렬화 함수는 하나(`serializeCard(lines, seps)`), 부서별 차이는 **칸 목록 데이터**(`MGMT_CARD`·`SALES_CARD`·`IT_CARD`)로만 둔다. 운영은 별도 문장 틀 함수(3-5).

### 3-2. 공통 값 규칙 (시트 수식 오류는 재현하지 않는다)
실물의 `76. 8. 28`·`76-8-28`(종료일)·`28000개월`(남은개월)·`46244개월`(사용여부)·영업 `남은개월:   개월` 은 시트 수식이 빈/글자 날짜를 계산한 결과다.
- **날짜 칸**(계약일·종료일·납품/교체일): 임대리스트 원값을 `fmtDot` 규칙으로(엑셀 일련번호 20000~60000 → 날짜, `2026-10-09` → `2026. 10. 9`). 연도 2000~2060 밖이면 빈칸. 날짜가 아닌 글자(경영 실물의 "가구" — 위탁 가구 품목 행에 임대리스트가 적어 둔 값으로 보임, 0단계 실측)는 **그대로**.
- **머리 줄 날짜는 두 자리 연도** `YY. M. D`(경영·영업 실물 모두), 본문은 `YYYY. M. D`, 접수일은 `M. D`(KST 저장 시각) — 실물의 혼용을 그대로 따른다.
- **남은개월** = 종료일 − 오늘(KST) 월수 → `N개월`. 종료일이 날짜가 아니면 빈칸(영업 실물의 `개월` 만 남는 꼴 금지). 지난 계약은 `만료`(Q8).
- **사용개월**(경영 "사용여부" 칸, Q6) = 오늘 − 계약일 월수, 계약일이 날짜 아니면 빈칸.
- 금액(기본임대료·평균임대료): `fmtWon` 규칙(소수 반올림, `₩150,000`, 글자면 그대로, 빈 값은 빈칸).
- 미수개월: "0" 이면 빈칸(실물 둘 다 빈칸).
- **업체명(머리·영업 "상호")** = 임대리스트 `업체명` 원문(CA열, "17N메이크건설양평현장매월마감"처럼 발행일·등급·마감구분이 이미 붙어 있는 표기), 줄바꿈만 공백으로. 없으면 `sheetVendorName(lease)` → `row.vendor`. `stripGradePrefix` 는 쓰지 않는다(CS 카드는 앞에 발행+등급을 따로 붙여서 떼지만 부서 실물은 원문 그대로).
- **전화번호는 가리지 않는다**: 기번·키맨·접수자연락처는 원문 그대로(방 안 업무 글, 시트 복사 때와 같음). 원문 보관 `kakao_messages` 는 적재 때 이미 가림(엣지 kakao-ingest). 이 문서·테스트 표본엔 가짜 번호(010-0000-xxxx)만.

머리(셀 복사, 탭): `등급 · 접수분야 · 모델명 · 업체명 · 종료일 · {YY. M. D} · 지역 · {지역} · 접수일 · {M. D}` (방문주기 없음)
```
{등급}\t{접수분야}\t{모델명}\t{업체명}\t종료일\t{종료일 YY}\t지역\t{지역}\t접수일\t{M. D}
(빈 줄)
임대여부:   {임대여부}   /   접수분야:   {접수분야}
상호:   {업체명}   /   임대리스트순번:   {순}
계약일:   {계약일}   /   종료일:   {종료일}
기본임대료:   {기본금액}   /   평균임대료:   {연평균}
```

- 실물 그대로 `접수자연락처` 뒤에는 콜론이 없다(양식 꼬임). 기본 = 실물 그대로 재현, Q11.
- 실물 `상호:    ` 처럼 공백 수가 들쭉날쭉한 것은 `SEP_LV`(콜론+공백 3칸) 하나로 통일.
- 영업 실물 "기본매수 컬러500/흑백3000", "추가장당 컬러100/흑백10" — 임대리스트 컬러·흑백 기본매수와 추가(컬)·추가(흑)을 `컬러{}/흑백{}` 로 이은 모양. 원천 키는 0단계 실측(vendor_info 에 `추가(컬)`·`추가(흑)` 열은 있음 — schema-snapshot-20261019.sql).

### 3-5. 운영지원 양식 — 자유 글 틀 (방 "운영팀내근스케줄이동", 봇 폰 10/26 초대됨)
실물은 정해진 표가 없는 **사람 말투 글**(대표 예: "안녕하세요 퍼스트에서 실고 납품 접수 부탁드립니다." + 날짜·업체명·싣는/납품 주소·ㄴ 담당자·품목 + "> 메모", 그 밖엔 "금일 우체국 발송건 2건 있습니다…" 같은 한두 줄). 그래서 운영은 카드가 아니라 **문장 틀**. 운영지원 폼 필드는 다른 부서와 같은 `DeptReceptionInput`(운영 고유 필드 없음 — `src/deptReception.ts` 122~147행, 접수분야 칩만 `소모품·배송/택배·설치·기타`). 있는 값만 쓰고 **빈 값이면 그 줄을 통째로 뺀다**.
```
안녕하세요 퍼스트에서 {접수분야} 접수 부탁드립니다.
(빈 줄)
날짜(요일) : {예정일 → "M월 D일(요)"}
업체명 : {업체}
주소 : {주소}
ㄴ 담당자 : {업체담당자} {전화번호}
품목/요청 : {접수내용 — 여러 줄 그대로}
(빈 줄)
접수자 {직원 이름}
```
- 예정일은 폼에서 사람이 넣은 값만(`input.scheduleDate`). `runDeptSave` 가 빈 예정일을 오늘로 채우는 것은 글을 만든 **뒤**라, 비어 있으면 날짜 줄이 빠진다 — 의도("날짜 미정"을 오늘로 오해하지 않게).
- 실물의 "싣는 주소/납품 주소" 두 갈래는 폼에 칸이 하나뿐이라 `주소` 한 줄. 갈래가 필요하면 접수내용에 적는다(폼 확장은 범위 밖).
- 특이사항(`notes`)은 설계상 DB 전용이라 기본은 안 싣는다. 실물의 `> 컨테이너 안에까지 납품 필요` 같은 줄로 싣고 싶으면 Q16.
- 처리자·접수유형·사내 요청자는 운영 글에 넣지 않는다(실물에 없음).
