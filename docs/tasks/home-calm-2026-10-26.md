## 1. "시작 전" 상태 (가장 효과 큼: 빨강 약 67 → 0)

### 규칙 (순수 함수, kpiCompute.ts)
```
경과 영업일 e = bizDays(기간 시작, 오늘, holidays)          // 오늘 포함
기간 영업일 n = bizDays(기간 시작, 기간 끝, holidays)
시작 구간 = e ≤ max(2, ceil(n × 0.15))
```
| 기간 | n(보통) | 시작 구간 | 실제 뜻 |
|---|---|---|---|
| 주 | 5 | e ≤ 2 | 월·화 (월요일이 공휴일이면 화·수) |
| 월 | 20~23 | e ≤ 3~4 | 대략 1~5일 |
| 분기 | 약 62 | e ≤ 10 | 첫 2주 |

- 판정: **누적 지표**(basis 가 zero·ratio·none 이 아니고 better ≠ down)이며 목표 > 0, 실적 = 0, 시작 구간이면 → 새 상태 `notStarted`("시작 전", 회색).
- 그 밖에는 지금 규칙(50% 고정)을 그대로 쓴다. 작을수록 좋은 지표(zero)·비율 지표(ratio)·열린 건 지표(pace 없음)는 해당 없음.
- 기간은 **그 행의 실제 기간**(effectivePeriod — 예: 이번 주를 골라도 K10 은 이번 달)으로 센다.
- 숫자(실적·목표·%)는 하나도 바뀌지 않는다. 바뀌는 건 상태 글자와 색뿐이다.

### 같이 바뀌는 곳
| 자리 | 지금 | 바꾼 뒤 |
|---|---|---|
| 달성표 상태 알약·CS 숫자·% 알약·막대 | 빨강 "부족" | 회색 "시작 전" (none 과 같은 회색, 글자만 다름) |
| 달성표 팀 타일 | 빨간 바탕 0% | 회색 바탕 `0%`, 아래 `0/8` |
| 팀 카드 알약 | 빨강 "부족" | 주요 목표 판정이 전부 시작 전이면 회색 "시작 전". 부족이 하나라도 있으면 지금처럼 "부족" |
| 팀 카드 미니 타일 4 | 빨간 바탕 0% | 회색 |
| 펼친 행 개인 칩 | 목표 있는데 미달이면 빨강(`done` 아니면 behind) | 시작 구간 + 실적 0 이면 회색 칩 |
| 주의 한 줄 "가장 낮은 % 부족 지표" | 0% 지표가 뜸 | behind 만 뽑으므로 자동으로 빠짐 |

### 결정 대기 1개 (팀장·사용자 확인)
시작 구간에서 실적이 0 이 아니고 50% 미만이면 지금 규칙상 빨강이다. 그래서 **월요일 오후에 첫 1건을 올리면 회색이 빨강으로 바뀌는 역설**이 생긴다.
- (가) 지시대로: 0 일 때만 시작 전, 나머지는 지금 규칙.
- (나) **추천**: 시작 구간에서는 빨강을 쓰지 않는다. 0 이면 회색 "시작 전", 0 보다 크면 파랑 "순항". 구간이 지나면 지금 규칙.
- 둘 다 순수 함수 안의 한 줄 차이라서 구현량은 같다.
