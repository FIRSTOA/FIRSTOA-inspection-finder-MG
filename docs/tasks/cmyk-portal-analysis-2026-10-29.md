## 0. 요약 10줄

1. CMYK = 에이치에스 주식회사(서울 구로, 대표 김진호)의 렌탈 관리 SaaS. 2020-12 시작, printermonitoring.co.kr 로 5년간 약 200개사에 무료 → **2026-07 "시즌2"로 유료 전환**(cmyk.ne.kr). [사실]
2. 한 줄로: **카운터 자동 수집 → 계약 조건대로 거래명세서 자동 생성 → 세금계산서(하이웍스)·CMS(효성) 자동 생성 → 거래원장·미수 → 경영 보고서 9종**, 여기에 A/S·재고·QR 접수를 붙인 "청구 중심 올인원". [사실]
3. 우리 회사로 치면 **한조(카운터 수집) + 이카운트(청구·원장) + FIELD 의 A/S 일부 + StockBoard(재고)** 를 한 프로그램으로 묶은 것이다. [실측: 우리 쪽 구성]
4. 요금 예시: 기본형 월 39,000원(200대)·표준형 79,000원(300대)·그 이상 맞춤형 협의. 우리 임대중 **10,881대** 는 맞춤형 구간. [사실 / 실측: 문서의 임대중 대수]
5. 개발 속도: 2026-07~10 업데이트 공지 9회 19항목(월 4~5개). 방향은 **모바일 현장화·비대면 접수·미수/만료 관리·부품 수명 판단**. FIELD 같은 기간 커밋 1,274개 — 반영 속도는 우리가 빠르나 CMYK 는 "돈 흐름"을 끝까지 잇는다. [사실/실측]
6. **FIELD 가 앞선 것**: 카톡방 중심 업무 흐름, 현장 양식 깊이(매수·잔량·여분·보관·한조 유무·사진 AI), 서비스접수 6종+시트 미처리, 통합검색 360+AI 질문, OKR·KPI·순위표, 워킨맵 분기 진행률, 미수 방문이력(법무 기준), 재계약 준비(이카운트 대장 분석), 고객 리포트. CMYK 에는 카톡이 한 줄도 없다.
7. **FIELD 에 없는 것(핵심 4)**: ① 카운터가 **기기별 날짜별로 자동 쌓이는 원장** ② **소모품 잔량** 실시간 감시 ③ 계약 조건(기본매수·초과단가·청구주기)이 **구조화된 데이터** ④ 고객 **셀프 접수(QR 콜카드·고객 링크)**. 청구·세금계산서·CMS·원장은 이카운트 영역이라 "FIELD 에 없음"이 곧 "회사에 없음"은 아니다.
8. CMYK 의 "API 연동 가이드"는 **하이웍스·효성CMS 를 CMYK 에 붙이는 법**일 뿐, CMYK 데이터를 밖(FIELD)으로 꺼내는 API 문서는 포털 어디에도 없다. 연동은 엑셀 내려받기 수준이다. [사실: 153건 전수 확인]
9. 추천: **CMYK 전면 도입이 아니라, CMYK 가 보여 준 기능 4개를 FIELD+노트북으로 만든다** — P1 카운터 원장(이메일 카운터+한조 내보내기) → P2 부품 수명·소모품 0/10/20% 주간 리포트 → P3 QR 콜카드 셀프 접수 → P4 지도에 소모품 경고·미방문 겹치기. 청구·세금계산서·CMS 는 만들지 않는다(이카운트).
10. 결정 필요 3개(9절): 대표 의도(도입 검토 vs 기능 참고) · 이카운트 유지 확정 · 카운터 원장 착수 순서.

## 7. 결론 세 묶음

### (A) FIELD 가 더 뛰어난 것 (근거)

1. **카톡 업무 흐름** — 보내기 한 번에 저장→카톡방→방문 집계→워킨맵 색→일정 정리(03장). CMYK 는 카톡 연동이 전혀 없고 고객 연락은 메일뿐[사실: 153건에 카톡·알림톡 언급 0]. 우리 회사는 업무가 카톡방에서 돈다.
2. **현장 양식의 깊이** — 여분·여분 보관 위치·한틴이카(외부 수집 유무)·주차비·도착/소요 시간·점검 체크리스트·매수/잔량 사진 AI. CMYK A/S 처리는 "처리 내용·고장 유형·부품·사진·서명" 수준.
3. **접수 일원화** — 서비스접수 6종 + 시트에 직접 적힌 접수까지 합친 미처리 현황판. CMYK 는 A/S 한 종류.
4. **통합 검색 360 + AI 질문** — 23표를 업체 하나로, 사람·팀·OKR·KPI 질문. CMYK 는 메뉴별 단어 검색.
5. **팀 운영 지표** — 홈 KPI·주간현황판·순위표·OKR(분기→월→주차). CMYK 보고서는 매출·원가 중심이고 사람 성과는 엔지니어별 A/S 건수뿐.
6. **방문 계획** — 워킨맵(분기 마감 주차별 색·진행률·하루 목표). CMYK SL 은 주기만.
7. **미수 회수 활동** — 법무 기준 방문이력·소송 이관 준비. CMYK 는 원장 숫자·필터.
8. **재계약 협상 재료** — 이카운트 대장 해석 → 활용률·추천 플랜. CMYK 는 "3개월 내 만료" 필터.
9. **비용 구조** — 자체 개발이라 대수 과금 없음. CMYK 예시 요금을 대당으로 환산하면 195~263원/대·월, 10,881대면 **월 210만~290만원대로 추정**(맞춤형이라 실제 견적은 다름, 외부 서비스 비용 별도).

## 9. 사용자에게 물을 것 (3개)

1. **대표님 의도** — CMYK 를 "우리 회사가 갈아탈 후보"로 보시는가, "필요한 기능 목록을 뽑는 참고"로 보시는가? 후보라면 데모 계정 둘러보기·견적 문의가 먼저다(8절 ④).
2. **청구·세금계산서·CMS·원장은 계속 이카운트** 로 두고 FIELD 는 만들지 않는다 — 이 선을 확정해도 되는가? (확정되면 B8·B10 은 범위 밖으로 닫는다)
3. **P1 카운터 원장 착수 순서** — (가) 이메일 카운터 먼저(대표 IMAP 승인, 메일 계정 종류 캡처) 또는 (나) 한조 내보내기 먼저(한조 화면의 엑셀·CSV 내보내기 메뉴 캡처). 받기 쉬운 것부터 시작한다.
