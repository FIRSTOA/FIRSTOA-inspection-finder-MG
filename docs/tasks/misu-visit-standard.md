# 미수 소송이관 절차 · CS 방문이력 기준 (법무팀 문서 전사, 2026-10-22 사용자 제공 사진 4장)

> 소송방·철수 병목의 원인은 기준 부재. 절차를 고정하고, 현장 작성 도구까지 함께 배포한다. (법무팀 요청)
> 기록이 부족하면 소송 이관 후 다시 방문해야 한다. 한 번 나갈 때 아래만 채우면 재방문은 없다.

## ① 이관 절차 — 순서 고정

| 단계 | 담당 · 시점 | 내용 |
|---|---|---|
| 1 | 관리부 · 1~3개월 | 유선 독촉 — 주 1회 문자·메일 미수내역 |
| 2 | CS · 4개월~ | 1차 안내 방문 — 2차 경고 방문(철수·소송 가능) |
| 3 | 관리부 최종고지 | 해지 · 기기반환 요구 — 소송이관 예정 통보(문자+메일) |
| 4 | 방문접수 → 철수접수 | CS 접수 완료 확인 후 관리부가 선행방 접수 |
| 5 | 소송방 이관 | 관리부 게시 — 법무팀 검토 3영업일 |

- **CS 방문접수가 끝나기 전에는 선행방 철수접수를 올리지 않는다.** 순서가 뒤바뀐 건은 접수 취소, 필수기재 누락 건은 소송방 반려.

## ② CS 방문 후 반드시 남길 5가지

1. **응대한 사람의 이름·직위** — '직원'은 반려. 이름과 직위까지. 대표자가 아니었다면 대표자 연락처를 받았는지.
2. **문이 잠겨 있었다면 그 근거** — 우편물이 얼마나 쌓였는지, 간판이 남아 있는지, 옆 가게가 뭐라고 하는지(셋 중 하나 이상).
3. **기기 반환을 요구했는지 (2차 방문 필수)** — 없으면 기기값을 청구할 수 없다. 누구에게 말했고, 뭐라 답했고, 반환 방법까지 안내했는지.
4. **사진 4장** — ① 외부(간판+호수) ② 출입문 ③ 기기 전체 + S/N 라벨 ④ 안내문 부착·투입.
5. **현장 판단과 사유** — 계속 독촉 · 철수 · 소송이관 중 하나를 고르고, 사유 한 줄.

> **반환 요구 기록이 없으면 기기값을 청구할 수 없다.** 형사 진행 요건 — 소유권(계약서) · 반환 요구 · 불응. 지금까지 이 기록 없이 이관된 건은 기기대금을 빼고 다시 청구해야 했다.

## 이렇게 오면 반려 (X → O 예시)

| 항목 | X (반려) | O |
|---|---|---|
| 응대자 | 직원 | 김○○ / 점장 / 대표자 연락처 확보(010-0000-0000) |
| 운영 여부 | 문 잠김 | 문 잠김 / 우편물 3주치 적치, 간판 유지, 옆 가게 "2개월째 안 열었다" → 폐업 추정 |
| 미수 독촉 | 안내함 | 점장에게 구두 안내, 안내문 봉함 후 전달. "대표에게 전달하겠다", 납부 약속 없음 |
| 기기 반환 | (빈칸) | 점장에게 반환 요구 고지, 반송 주소 안내. "대표 확인 후 회신" 후 무응답 |
| 사진 | 기기 1장 | 외부 · 출입문 · 기기+S/N · 안내문 4장 |

## 현장에서 지킬 4가지

1. **08시 ~ 21시 사이에만** — 그 밖의 시간 방문·전화·문자는 채권추심법 위반.
2. **채무 사실과 금액은 대표자·담당자에게만** — 직원·옆 가게·건물 관리인에게는 영업 여부만 물어본다.
3. **안내문은 반드시 봉함** — 봉투 겉면에 금액이나 '미납'이 보이면 제3자 고지 문제.
4. **잠긴 곳은 절대 열지 않는다** — 문을 따거나 기기를 들고 나오는 건 계약서에 권한이 있어도 안 된다.

- "신용불량 등록된다", "구속된다" 같은 말은 사실과 다르고 회사 리스크. 안내는 법무팀 표준문안 범위 안에서만.
- 작성은 사내 배포된 **'CS 방문이력 작성기'**를 쓰면 버튼만 눌러 채워진다. 판단이 애매한 건은 법무팀으로 바로 연락.
- 배포물: 절차서(전 부서) · CS 방문이력 양식 · 관리부 소송이관 게시양식 · 모바일 작성기. 4대과업 연결: 매출 안정화 · AI 효율화 · 지식 공유.
