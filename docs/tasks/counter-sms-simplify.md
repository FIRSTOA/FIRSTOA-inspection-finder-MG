**신규 판정 재료가 이미 있다**: 자동 반영과 수동 추가는 카드의 `added_at`과 log 항목의 `at`에 **같은 시각**을 적는다(`counter-inbox-ingest/index.ts:99`·`:104`의 `now`, 수동 `CounterSms.tsx:398`·`:409`의 `stamp`). 그래서 log 한 줄의 신규 업체 이름을 카드에서 거꾸로 찾을 수 있다. 달마다 batch가 새로 생긴다(`newBatch`, `loadBatch:202`는 팀의 최신 1개).

## 3. 데이터 설계: SQL 0 · 엣지 0
- **신규** = `added_at`이 batch `created_at`보다 2분 넘게 뒤인 카드. 처음 올린 목록에 있던 업체는 신규가 아니고, 그 뒤에 자동이나 수동으로 추가된 업체가 신규다. 신규 수 = 그런 카드의 수.
- 머리 상태 줄 = `batchTargets` 전체(두 등급 합)에서 센다. 숫자 원천은 지금의 `sentCount`·`doneCount:597-598`과 같다.
- 변경 이력 = `batch.log`만 원천으로 쓴다(최신이 위). 상단 `autoDone` 블록은 같은 사건의 문자열 복사본이므로 **화면에서 뺀다**(조회 `:140`은 남겨도 되고 빼도 된다. 구현서가 판단).
- "📥 자동으로 못 넣은 목록"(`:568-585`)은 사람이 할 일이 있으므로 **그대로 둔다**.

## 4. 화면 흐름
1. 머리(팀 칩 아래) 한 줄 상태: **`10월 마감 · 24곳 · 보냄 4 · 완료 0 · 신규 3`**. 신규를 누르면 신규 필터가 켜진다. 진행 막대는 남긴다. [새로고침]은 그대로 두고, [목록 삭제]는 ⋯ 메뉴로 옮긴다.
2. 그 아래 접힌 **"이 화면은?"**(처음 한 번 펼친 상태, localStorage로 기억) 3줄:
   ① 관리부가 마감방에 올린 목록이 자동으로 들어옵니다. 새로 생긴 업체에는 **신규**가 붙습니다.
   ② 업체 카드를 눌러 고객에게 카운터 요청 문자를 보내면 **보냄**이 됩니다.
   ③ 고객이 보낸 카운터 사진을 **[카운터 전송]**으로 마감방에 올리면 **완료**가 됩니다.
   그리고 배지 뜻 한 줄: 다시 올라옴 · CMS(따로 오는 CMS 마감, 숫자 = 결제일) · ⭐ 새 담당 · 🚫 막은 번호.
3. 접힌 **"변경 이력 n"**: 한 항목 = 한 줄 `10-23 04:19 박지은(또는 자동) · 신규 1 · 중복 2 · 목록에 없는 열린 곳 17 [보기]`. [보기]를 누르면 그 줄의 업체명(신규 = 같은 `at`의 카드, 중복 = `skipped`, 없는 곳 = `missing`, 빠져서 완료 = `dropped`, 삭제 = `removed`)이 칩으로 펼쳐진다. "목록에 없는 열린 곳" 옆에는 "관리부가 끝낸 곳이면 카드에서 완료"라는 안내를 붙인다.
4. 등급 탭: **[일반 S·NN·N n] [우수 V·SS n]**(이름은 Q2). 그 옆에 정렬 [처리 순 | 추가된 날짜순]과 필터 칩 [전체 | 신규]를 둔다.
5. 카드 한 장(폰 390px 기준 3줄):
   - 1줄: 업체명 + 오른쪽 상태 알약 1개(**안 보냄**=없음 / **보냄** 초록 / **완료** 남색) + **신규 10/23**(초록 외곽선).
   - 2줄: `2대 · 010-…` (지금과 같음) + 주의 배지는 최대 1개, 다음 순서로 고른다: **완료 뒤 다시 올라옴**(빨강) > **보낸 뒤 다시 올라옴**(주황) > **다시 올라옴 n회**(회색). 그 밖에 CMS·⭐·🚫·이름 유사.
   - 3줄: 보낸 날·완료 날(지금 `:673-678`과 같음). "목록 MM/DD" 배지는 없애고 날짜를 이 줄로 옮긴다("추가 10/23 박지은").
   - 단추: 단계별로 **주 단추 1개**만 둔다. 안 보냄 = [문자 보내기](= 카드 누름, `openSendRow`) / 보냄 = [📷 카운터 전송](사진 팀만, 아니면 [완료]) / 완료 = 없음. 나머지(완료·완료 취소·전송 취소·삭제)는 **⋯ 더보기** 메뉴에 넣고, 삭제는 지금처럼 확인 창을 띄운다.
6. 완료 접기(`:695-699`)는 그대로 둔다.

## 6. 위험·열린 질문 (한 번에)
- **Q1** "신규"의 뜻: (가) 이번 달 목록이 처음 올라온 **뒤에** 추가된 업체(제안, 쿼리 0) / (나) **지난달 목록에 없던** 업체(지난 batch를 한 번 더 조회해야 함). 어느 쪽인가요?
- **Q2** 등급 탭 이름 "일반 / 우수"로 괜찮나요? 아니면 "S·N급 / V·SS급"처럼 글자를 그대로 둘까요?
- **Q3** 상단 "자동 반영" 초록 블록을 아예 빼고 변경 이력으로만 볼까요? (제안: 뺌. 실패 목록 노란 블록은 유지)
- **Q4** "목록에 없는 열린 곳"(지금 17곳)은 카드에도 "최근 목록에 없음" 회색 배지로 표시할까요? (제안: 2단계)
- 위험: 옛 batch는 `added_at`이 없는 카드(`extended=false`)가 있어 신규를 판정할 수 없다 → 신규로 치지 않는다. 수동 맞추기 log에는 `missing`이 없다 → [보기]에서 해당 묶음을 숨긴다.
