# 워킨맵(`src/WalkingMap.tsx`) 개선 감사 — 2026-09-12

> 팀장 요청 "워킨맵 개선할 점 전부 찾아줘"에 대한 전수 감사. 코드 실독 + anon 키 실측 기반.
> 이미 끝난 것(5-gram 색인, 카카오 캔버스 점·라벨, 미러 팀 한정, 하단 띠 📅, 목록 상단바 정리, 지도 조건 메뉴 등급 필터)은 제외.

## 요약
1. 기능은 풍부하지만 가장 잦은 동작 "방문 후 색칠"이 4탭이고, 모바일에서 지도↔목록 전환마다 카카오 지도를 통째로 다시 만든다.
2. 통신량 과다: 30초마다 4,557행 ≈5.1MB 재수신(하루 실제 변경 21행), 앱 복귀마다 370일치 방문기록·원본 ≈7MB×2. 저장 실패·동시 수정이 소리 없이 사라진다.
3. 완료 셈법·공휴일·재계약 분모 정의가 4~5곳에 복제. "교체" 불러오기는 확인 없이 팀·분기 목록을 지운다. 순수 로직 단위 테스트 없음.
