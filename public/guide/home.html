8. 빠른 사용 안내 — 4가지, 펼쳐서 읽기

"필요한 업무만 펼쳐 확인하세요." 제목 줄을 누르면 그 항목만 펼쳐지고(아이콘이 파랗게), 다른 것을 누르면 이전 것은 접힙니다. 안내문은 아래와 똑같습니다.

처음 사용할 때 — 접수부터 현장 완료까지
  1. 서비스접수에서 임대리스트를 검색해 접수하고, 확인 팝업에서 주소·접수자를 점검합니다.
  2. 저장하면 일정리스트에 자동 등록됩니다 — 담당자를 배정하고 상세 팝업에서 통화·네비를 씁니다.
  3. 워킨맵·FIELD에서 현장 처리 후 해당 업무방으로 전송합니다.
  4. 처리 결과는 일일방문일지·주간현황판·업무관리에 자동 집계됩니다.
접수 → 일정 → FIELD 연동 — 접수 한 번으로 일정·양식까지
  1. 접수 저장 시 '일정리스트에도 등록'을 켜두면 오늘 날짜로 일정이 생깁니다.
  2. 일정리스트에서 완료·익일 처리하면 접수 현황 상태도 함께 바뀝니다.
  3. 일정 상세 팝업의 FIELD AS 버튼으로 접수 내용이 채워진 양식을 바로 만듭니다.
  4. 주소가 임대리스트와 다르면 접수 현황 📍 필터에서 모아 워킨맵·임대리스트에 반영합니다.
FIELD 작성·전송 — 원본 변환, 기기 수정, 사진, 전송
  1. 원본 붙여넣기, 사진 변환 또는 거래처 검색으로 양식을 불러옵니다.
  2. 기기선택에서 위치·모델·시리얼·자산기번·내용을 확인합니다.
  3. 작성 칸과 결과 미리보기가 같은 내용인지 최종 확인합니다.
  4. 사진을 첨부하고 점검·AS·물류 등 해당 업무방으로 전송합니다.
