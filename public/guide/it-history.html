2. DB 연결 — 처음 한 번만

주소가 저장돼 있지 않으면 화면을 열 때 이 입력 칸이 자동으로 열려 있습니다. 이미 연결된 뒤에는 오른쪽 위 연결 상태 버튼을 눌러야 보입니다.

화면 재현
Apps Script 웹 앱 /exec 주소연결 확인
기존 PC DB Apps Script에 API 어댑터를 적용한 뒤 배포 주소를 한 번만 입력합니다.
  1. 주소를 붙여 넣는다 — 관리자가 알려준 Apps Script 웹 앱 주소(끝이 /exec).
  2. 연결 확인을 누르면 서버에 살아 있는지 물어봅니다(ping). 그동안 화면 중앙에 파란 회전 아이콘이 돕니다.
  3. 성공 → 입력 칸이 닫히고 오른쪽 위에 초록 알림 기존 PC DB와 연결했습니다. 버튼은 DB 연결됨으로. 곧바로 지식 DB 전체 목록을 한 번 불러옵니다.
  4. 실패 → 빨간 알림(예: IT 기술 DB에 연결하지 못했습니다.). 주소를 다시 확인하고 재시도.
빈 칸으로 연결 확인을 누르면"Apps Script 배포 주소를 입력해 주세요."가 뜨고, 저장돼 있던 주소도 지워져 DB 연결 필요 상태가 됩니다. 연결을 끊고 싶을 때 이렇게 쓰면 됩니다.
연결 안 된 상태에서 검색·퀴즈·등록을 누르면아무것도 실행되지 않고 이 주소 입력 칸이 대신 열립니다. 먼저 연결하라는 뜻입니다.

3. 원본 화면 — 예전 PC DB를 그대로

예전에 쓰던 PC DB 웹 화면을 이 화면 안에 통째로 띄웁니다(높이 최소 680px, 화면 크기에 맞춰 늘어남). 안에서 하는 조작은 전부 PC DB 원본 그대로 동작합니다 — 웹앱은 보여주기만 합니다. 복사·붙여넣기도 됩니다.

연결돼 있으면PC DB 원본 화면이 흰 카드 안에 나옵니다. 여기서 수정·삭제한 것은 지식 DB·처리이력·IT 재고 탭에도 그대로 반영됩니다(같은 데이터).
연결 안 됐으면노란 안내 카드: "원본 PC DB 연결이 필요합니다" — "상단의 DB 연결 필요 버튼을 눌러 Apps Script 웹 앱 주소를 입력하세요."
이 화면에서 등록한 이력을 고치거나 지우려면기능 탭에는 수정·삭제가 없습니다. 원본 화면 탭에서 PC DB 방식으로 고치세요.

8. 이럴 땐 어떻게

다른 PC(폰)에서 열었더니 "DB 연결 필요"예요

연결 주소는 기기(브라우저)마다 따로 저장됩니다. 오른쪽 위 DB 연결 필요를 눌러 같은 주소를 한 번 더 입력하고 연결 확인을 누르세요. 그 기기에서는 그 뒤로 기억됩니다.

검색했는데 예전 결과가 먼저 보이고 잠시 뒤 바뀌어요

정상입니다. PC DB가 느려서 마지막 결과를 먼저 보여주고 뒤에서 최신본으로 바꿉니다. 방금 등록한 이력이 안 보이면 몇 초 기다리거나 전체 보기 후 다시 검색하세요.

"응답 시간이 초과되었습니다"가 떠요

20초 동안 PC DB가 답하지 않은 것입니다. 잠시 뒤 검색을 다시 누르세요. 계속 그러면 원본 화면 탭에서 PC DB 자체가 열리는지 확인하고, 안 열리면 관리자에게 Apps Script 배포 상태를 문의하세요.

원본 화면이 하얗게 비어 있어요

PC DB 웹앱을 그대로 띄우는 것이라 PC DB 쪽이 느리거나 로그인이 필요할 수 있습니다. 새로고침해 보고, 그래도 안 되면 지식 DB·처리이력 탭으로 검색은 계속 할 수 있습니다(같은 데이터).

등록한 이력을 잘못 적었어요

이 화면의 기능 탭에는 수정·삭제가 없습니다. 원본 화면 탭(PC DB)에서 그 행을 찾아 고치세요. 알림에 나온 ID 번호를 기억해 두면 찾기 쉽습니다.

퀴즈가 10문제를 골랐는데 더 적게 나왔어요

서버에서 문제 60개를 받아 고른 레벨만 남기기 때문에, 그 레벨 문제가 적으면 그 수만큼만 나옵니다. 전체로 놓으면 10문제·20문제가 다 채워집니다.

최근 검색어에 이상한 말이 남아 있어요

결과가 1건 이상 나온 검색어는 자동으로 남습니다. 검색창 아래 지우기를 누르면 최근 검색어 8개가 한 번에 지워집니다(이 기기에서만).

탭을 바꿨더니 검색어가 사라졌어요

탭을 바꾸면 검색어·결과·상세 창이 비워지고 전체 목록을 새로 불러옵니다. 같은 말을 다른 탭에서 찾으려면 최근 검색어를 한 번 눌러 주세요.
