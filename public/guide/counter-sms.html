5. 문자 문구는 어떻게 만들어지나

문구 = 등급군 인사말 + 기종별 확인 방법 + 마무리말. 기종은 원문에서 자동으로 찾고, 문구 세트는 지역(팀)별로 다를 수 있습니다(7번).

기기 1대 (기종 1개)
(인사말 (단일 기기)) ▶ 기종: X3220NR ▶ 방법: 복사기 숫자 키패드 위 카운터 클릭 후 화면에서 인쇄 눌러주시고 나온 출력물 사진찍어 보내주시면 됩니다. (마무리말 (단일))
기종 문구 자체가 "안녕하세요"나 "사용량확인차"로 시작하는 완결형(5473 등)이면 인사말 없이 그 문구 + "(기종: …)" + 마무리말만.

6. ✂️ 직접 붙여넣어 변환 (개인용)

공유 목록에 없는 업체를 급히 보낼 때만 씁니다. 팀 목록 아래 접힌 줄 "✂️ 직접 붙여넣어 변환 (개인용) — 공유 목록에 없는 건을 급히 보낼 때"를 누르면 펼쳐집니다.

  1. "현재 {지역} 문구 세트로 변환됩니다" — 아래 📍 지역 선택으로 바꿀 수 있습니다(내 선택은 이 브라우저에 기억).
  2. 카톡 마감 목록을 붙여넣고 [🔍 마감 문자 변환] → "N개 블록을 인식했습니다." 카드 목록(🟢/💎 탭)이 아래에 생깁니다. [초기화]는 붙여넣은 글과 결과를 모두 지움.
  3. 카드를 누르면 같은 전송 창이 열립니다. 다만 개인용이라 ✓ 표시가 남지 않습니다(초록 안내 상자도 없음).
  4. 틀린 곳은 "🔧 인식 결과 수정 (N건)"을 펼쳐 업체명(등급)·기종(드롭다운)·연락처를 고치면 카드가 바로 다시 계산됩니다. 이름·직함이 잡힌 번호는 "👤 홍길동 과장(010-…)"으로 아래에 표시.

8. 이럴 땐 어떻게

목록에 내 팀 업체가 안 보여요

팀 알약이 다른 팀으로 되어 있거나(★가 내 팀), 등급군 탭(🟢/💎)이 반대쪽일 수 있습니다. 둘을 확인하고 [새로고침]. 그래도 없으면 관리부가 아직 이번 달 목록을 올리지 않은 것입니다.

업체 두 곳이 한 카드로 합쳐졌어요

같은 등급군에서 같은 휴대폰 번호를 쓰면 한 통으로 묶습니다(담당자가 같으면 한 문자에 기종별 방법을 다 넣는 게 맞기 때문). 정말 다른 담당자라면 목록을 올린 사람이 [마감 목록 올리기]의 인식 결과에서 번호를 나눠 다시 등록해야 합니다.

기종이 "기본 기종"으로 나와요

원문에 기종을 알아볼 글자가 없었습니다. 개인용 변환에서는 "🔧 인식 결과 수정"의 기종 드롭다운으로 바꿀 수 있고, 팀 목록은 원문에 기종을 적어 다시 올려야 합니다. 자주 나오는 기종이면 ⚙ 문구 설정의 기종별 안내 문구에 추가를 요청하세요.

✓가 있는데 고객이 문자를 못 받았대요

✓는 문자앱을 연 기록입니다. 보낸 사람의 문자앱 발신 내역을 확인하고, 실제로 안 갔으면 [전송 취소] 후 다시 보내세요.

번호가 두 개인데 어느 쪽으로 보내나요

전송 창에서 하나만 고릅니다(같은 문자를 두 번 보내지 않기 위해). 👤 이름·직함이 붙은 번호가 원문에서 담당자로 읽힌 것입니다.

문구를 고쳤는데 다른 팀원 화면은 그대로예요

[변경사항 저장]을 눌렀는지 확인하세요. 저장했다면 팀원이 이 화면을 다시 열 때 반영됩니다(이미 열어 둔 화면은 새로고침).

지난달 목록을 다시 보고 싶어요

화면에는 팀별로 가장 최근 목록 하나만 보입니다. 지난달 목록은 삭제되지 않았지만 화면으로는 볼 수 없으니 관리자에게 요청하세요.
