증상 사진 (최대 6장)

  1. 점선 네모(🖼)를 누르면 파일 선택창이 열립니다. 여러 장 한 번에 고를 수 있고, 6장을 넘는 만큼은 잘립니다.
  2. PC에서는 사진 칸을 한 번 클릭한 뒤 Ctrl+V로 클립보드 이미지를 바로 붙일 수 있습니다("클릭 후 Ctrl+V로 붙여넣기 가능").
  3. 올리는 동안 네모에 "…"가 보이고, 끝나면 썸네일이 붙습니다. 썸네일 오른쪽 위 ×로 빼고, 썸네일을 누르면 원본이 새 탭에 열립니다. 폰 사진(HEIC·고화소)은 1600px로 줄여 올립니다.
  4. 실패하면 토스트 "사진 업로드 실패: …". 사진은 카톡에 공개 링크로 실리고(카톡봇은 글만 보냄), 접수 기록·일정 상세에도 남습니다.

접수 접수 — 저장 + 시트 + 일정리스트

  1. 업체가 없으면 결과 줄에 "업체를 선택(또는 입력)하세요."만 뜨고 멈춥니다.
  2. 접수를 DB에 저장(상태 "접수")하고, 접수 지역 팀에게 웹푸시 "새 접수 — 업체명"이 갑니다(접수자 본인 제외).
  3. 일정리스트에 오늘 일정을 만듭니다 — 팀은 지역 글자, 시간은 지금 시각, 상태 "접수", 접수내용 = 증상, 메모 = 양식 전문, 제목 = 양식 첫 줄. 같은 접수로 이미 일정이 있으면 새로 만들지 않습니다. 이 버튼은 네이버에 올리지 않습니다.
  4. 순번이 있거나 신규면 접수시트 기입을 뒤에서 시작합니다(결과 줄 옆 "접수시트 기입 중…").
  5. 결과: "접수 완료 ✓ + 일정 등록 — 폼 유지 중 (네이버·카톡은 옆 버튼)". 폼은 지워지지 않으니 이어서 [네이버 캘린더]·[카톡 전송]을 누르면 됩니다.
원격이관 탭에서는 버튼 이름이 "접수 (저장+시트)"파란 버튼으로 바뀌고, 저장(상태 "원격대기") + 원격 시트 기입 후 폼이 초기화됩니다. 결과 줄 "원격 접수 저장됨 (대기)". 방문이 없는 건이라 일정도 만들지 않습니다.

네이버 캘린더 네이버 캘린더 — 익일통합as에 등록

  1. 관리 탭의 "네이버 캘린더 미러" 스위치를 먼저 확인합니다. 꺼져 있으면 "네이버 캘린더 실패: 관리 탭에서 '네이버 캘린더 미러'가 꺼져 있습니다".
  2. 아직 저장 전이면 먼저 접수를 저장합니다(한 번만).
  3. 네이버 익일통합as 캘린더에 제목 = 양식 첫 줄, 날짜 = 오늘, 시간 = 팀 시간(A09/B12/C15/D18/E21), 장소 = 방문 주소, 내용 = 양식 전문으로 등록합니다. 접수 번호로 고정 키를 쓰기 때문에 두 번 눌러도 중복 등록되지 않습니다.
  4. [접수]로 만든 일정리스트 일정이 있으면 그 일정에 네이버 연결(uid)을 저장해, 일정리스트에서 완료·익일·삭제할 때 네이버도 함께 움직입니다.
  5. 결과: "네이버 캘린더 완료 ✓ — 폼 유지 중, 다음 단계를 이어서 누르거나 [전체 실행]을 쓰세요."

카톡 전송 카톡 전송 — 팀 AS방으로 양식 보내기

  1. 양식이 없으면 "카톡 전송 실패: 보고양식이 비어 있습니다 — 순번 선택 또는 신규 정보를 입력하세요", 지역이 없으면 "…지역이 비어 있어 보낼 팀 방을 정할 수 없습니다 — 자동 입력값 수정(또는 신규 지역 칩)에서 지역을 입력하세요".
  2. 아직 저장 전이면 먼저 저장합니다. 그리고 지역 글자에 맞는 팀 AS방에 양식 전문을 게시 대기열에 넣습니다(카톡봇이 곧 게시).

  2. 눌리면 확인 팝업이 뜹니다: 🚗 실제 방문 주소(비면 빨간 "미기재 — 주소를 확인하세요!"), 접수유형·구분·업체명·기종·시리얼(기번)·자산기번·접수자 성함·접수자 연락처·증상·주소 10칸. 신규 거래처는 기종·기번·자산이 필수가 아닙니다.
  3. 빨간 칸이 있으면 "빨간 항목 N개 — 그래도 진행하려면 아래 확인에 체크하세요."
  4. 체크 두 개: "저장하면서 일정리스트에도 등록"(기본 켜짐 — 끄면 일정을 만들지 않음) / "방문 주소와 접수자·기기 정보를 확인했습니다 (AS방으로 전송됩니다)"(이걸 켜야 파란 버튼이 살아남).
  5. [확인하고 전송] → 저장 → 팀 AS방 전송 → 상태 "전송완료" → 일정리스트 등록(+ 네이버 미러가 켜져 있으면 뒤에서 네이버 등록) → 시트 기입 → 결과 "전송 완료 — {방 이름} + 일정 등록됨" → 폼 초기화.
전송만 실패하면"전송 실패: … — 접수는 저장됐어요. 다시 누르면 전송만 재시도합니다." 저장된 접수를 기억하고 있어서 다시 눌러도 접수가 두 번 생기지 않습니다. 일정 등록이 실패하면 토스트 "일정 등록 실패 — 전송·저장은 완료. 리스트의 [일정 등록]으로 다시 시도하세요."

  3. 구글시트 임대리스트 원본을 직접 고친 뒤 [시트 반영 완료] → 확인 "임대리스트 시트의 주소를 수정하셨나요? 확인 목록에서 제외합니다. (처리자와 처리일이 기록됩니다)" → 📍가 내려가고 "시트 반영됨 · 날짜 이름"으로 남습니다.

9. 이럴 땐 어떻게

[⚡ 전체]가 눌리지 않아요

하단 필수 칩 중 빨간 것이 있거나 양식이 아직 없을 때입니다. 흐린 버튼 자리를 누르면 "필수 입력이 비어 있어요: …"로 빠진 칸을 알려 줍니다. 기존 거래처는 순번도 필수입니다.

카톡이 "AS방 매핑이 없어 전송할 수 없습니다"라고 해요

그 지역(주로 지방) 방이 관리 탭 방 매핑에 없다는 뜻입니다. 접수·일정은 저장돼 있으니 양식 [복사]로 직접 게시하고, 관리자에게 매핑 추가를 요청하세요. 팀 지역을 잘못 자동 판정한 경우면 A~E 칩으로 고쳐 다시 [카톡 전송].

네이버에 안 올라갔어요

[접수]만 누른 경우 네이버는 올라가지 않습니다(옆 [네이버 캘린더]가 담당). [⚡ 전체]는 관리 탭 "네이버 캘린더 미러"가 켜져 있을 때만 뒤에서 올립니다. 스위치가 꺼져 있으면 [네이버 캘린더] 버튼이 "관리 탭에서 '네이버 캘린더 미러'가 꺼져 있습니다"라고 알려 줍니다.

같은 접수가 시트에 두 줄 생겼어요

10분 안에 같은 업체·구분을 다시 접수하면 "중복 접수 확인" 팝업이 뜨는데 [한 건 더 접수]를 누르면 두 건이 됩니다. 잘못 만든 건은 리스트에서 [삭제] — 다만 시트 행은 자동으로 지워지지 않으니 [시트 열기]로 직접 정리하세요.

지역이 "지방"으로 나오는데 경기 업체예요

임대리스트 담당지역에 D(경기) 개념이 없어 생기는 일입니다. 주소로 자동 보정되지만, 안 되면 팀 지역 D 경기를 누르세요. 접수시트 담당지역에도 고친 값이 들어가 다음 접수부터 반복되지 않습니다.

접수 리스트 상태가 "진행중"인데 원격 건을 아직 안 시작했어요

복합기 AS 건은 일정리스트에서 담당자를 배정하면 접수 리스트가 진행중이 됩니다. 원격·IT는 처리 저장된 시작 시각이 있을 때만 진행중입니다(입력만 하고 저장 안 하면 그대로).

[다시 검색]을 눌렀더니 적어 둔 내용이 다 지워졌어요

[다시 검색]은 폼 전체 초기화입니다(접수자·증상·사진 포함). 업체만 바꾸려면 검색칸에 새 업체를 쳐서 다시 고르세요 — 그러면 주소는 새 업체 것으로 바뀌지만 접수자·증상은 남습니다.

방금 접수했는데 리스트에 안 보여요

오른쪽 위 [새로고침]을 누르거나, 날짜·기간·유형 칩을 확인하세요(예: IT 탭에서 접수했는데 유형 칩이 "복합기"로 걸려 있음). 삭제한 건은 이 화면에서 다시 보이지 않습니다.
